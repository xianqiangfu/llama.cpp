# 困惑度 (Perplexity)

`perplexity` 示例可用于计算语言模型在给定文本语料库上的所谓困惑度值。
困惑度衡量模型预测下一个 token 的能力，值越低越好。
请注意，模型之间的困惑度**不**直接可比，特别是如果它们使用不同的分词器。
还要注意，微调通常会导致更高的困惑度值，尽管人类评分的输出质量会提高。

在 llama.cpp 中，基础模型的困惑度主要用于判断来自例如量化模型与 FP16 的质量损失。
贡献者的约定是，除非另有说明，否则使用 Wikitext-2 测试集进行测试（可以使用 `scripts/get-wikitext-2.sh` 获取）。
当列出数字时，所有命令行参数和编译选项都保持在默认值，除非另有说明。
llama.cpp 数字与其他项目的数字**不**直接可比，因为精确值强烈依赖于实现细节。

默认情况下，仅计算平均困惑度值和相应的不确定性。
不确定性是通过假设"正确"logit 的高斯分布然后应用误差传播来凭经验确定的。

可以通过记录 FP16 版本模型的 logit 来获得更多统计信息。
为此，为 `perplexity` 提供 `--kl-divergence-base path/to/logit/binary/file.kld`。
然后程序将记录所有 logit 并将它们以二进制格式保存到提供的路径。
**logit 文件将非常大，在使用 Wikitext-2 测试集时，LLaMA 2 为 11 GiB，LLaMA 3 为 37 GiB。**
获得文件后，为 `perplexity` 提供量化模型，通过 `--kl-divergence-base` 提供 logit 文件，最后提供 `--kl-divergence` 参数以指示程序应计算所谓的 Kullback-Leibler 散度。
这是衡量 FP16 和量化 logit 分布相似程度的度量，值为 0 表示分布相同。
平均 KL 散度的不确定性是通过假设每个 token 的 KL 散度遵循高斯分布来计算的。

除了 KL 散度外，还会使用 `--kl-divergence` 计算以下统计信息：

* 平均 FP16 PPL 与量化 PPL 的比率。不确定性在 logits 上估计，然后传播。此度量的对数也会计算和打印，如果 logit 分布相同，则为 0。
* 平均 FP16 PPL 与量化 PPL 的差值。不确定性在 logits 上估计，然后传播。
* "正确"token 概率的平均变化。正值表示模型在预测方面变得更好，负值表示变得更差。
* 模型之间"正确"token 概率的皮尔逊相关系数。
* "正确"token 概率变化的百分位数。正值表示模型在预测方面变得更好，负值表示变得更差。可用于判断量化中的噪声与质量损失。如果百分位数是对称的，则量化本质上只是添加噪声。如果负值明显大于正值，则表示模型实际上因量化而变差。
* token 概率变化的均方根。如果您假设量化只是在 token 概率上引起高斯噪声，那么这就是所述噪声的标准差。该值的不确定性是通过假设 token 概率的变化遵循高斯分布来计算的。相关讨论：https://github.com/ggml-org/llama.cpp/discussions/2875 。
* 相同的 top p：两个模型都将 token 分配为最高概率的百分比。不确定性是从二项分布的高斯近似中计算的。
