# llama.cpp/example/simple-chat

本示例演示 llama.cpp 的最小化用法，用于使用 GGUF 文件中的聊天模板创建简单聊天程序。

## 快速开始

运行以下命令，确保使用正确的模型路径：

```bash
./llama-simple-chat -m Meta-Llama-3.1-8B-Instruct.gguf -c 2048
```

## 参数说明

| 参数 | 说明 |
|------|------|
| `-m, --model` | 模型文件路径（必需） |
| `-c, --ctx-size` | 上下文窗口大小 |
| `-ngl, --n-gpu-layers` | GPU 层数 |
| `-t, --threads` | 使用的线程数 |
| `-b, --batch-size` | 批处理大小 |
| `--color` | 是否启用彩色输出 |
| `--reverse-prompt` | 反向提示词（用于控制对话流程） |

## 功能特点

- **聊天模板支持**：自动从 GGUF 文件加载聊天模板
- **交互式对话**：支持用户与模型进行多轮对话
- **上下文管理**：维护对话历史和上下文

## 使用场景

- 快速测试聊天模型
- 验证聊天模板是否正确加载
- 基本的对话交互测试

## 注意事项

- 需要使用支持聊天模板的模型
- 上下文窗口大小会影响对话历史的保留
- 模型会根据聊天模板格式化输入和输出

## 聊天模板

llama.cpp 支持从 GGUF 文件中自动读取聊天模板，包括：
- 用户消息格式
- 助手消息格式
- 系统提示词格式
- 特殊标记处理

这使得不同模型的对话格式可以自动适配。
