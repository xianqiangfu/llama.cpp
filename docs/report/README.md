# llama.cpp 技术调研报告 - 目录结构

## 报告概述

本报告是对 llama.cpp 项目进行全面技术调研的成果文档，整合了项目架构、核心原理、技术实现、使用指南和最佳实践等内容。

## 文档结构

### 主报告文件

- **00-前言.md**: 报告前言，包含报告目的、适用范围、阅读建议等
- **01-项目概述.md**: 项目简介、发展历程、核心特性、应用场景
- **02-架构设计.md**: 整体架构、模块划分、关键组件
- **03-核心原理.md**: 推理引擎、量化技术、KV缓存、采样策略
- **04-技术实现.md**: 硬件后端、多模态支持、推测解码等高级功能
- **05-使用指南.md**: 安装配置、基本使用、高级功能
- **06-开发指南.md**: 开发环境、API使用、扩展开发
- **07-最佳实践.md**: 性能优化、资源管理、部署方案
- **08-常见问题.md**: 故障排除、常见错误、解决方案
- **09-总结与展望.md**: 项目成果总结、未来发展方向

### 附录文件

- **附录A-技术规范.md**: GGUF文件格式、GGML张量计算库规范
- **附录B-硬件后端对比.md**: 各硬件后端详细对比和选择指南
- **附录C-量化技术详解.md**: 各种量化格式的技术细节
- **附录D-性能测试数据.md**: 各场景下的性能测试结果
- **附录E-代码示例.md**: 常见使用场景的代码示例
- **附录F-参考资料.md**: 相关论文、官方文档、社区资源

### 支持文件

- **diagrams/**: 流程图和架构图目录（从 docs/diagrams/ 复制）
- **images/**: 图片和截图目录
- **resources/**: 其他资源文件

## 文件命名规范

- 格式: `XX-标题.md`
- XX: 章节编号（00-09为主章节，A-F为附录）
- 标题: 中文描述，使用连字符分隔空格
- 扩展名: `.md` (Markdown格式)

## 内容组织原则

1. **层次清晰**: 每个章节有明确的主题和边界
2. **逻辑连贯**: 章节之间有清晰的逻辑关系
3. **交叉引用**: 使用Markdown链接实现章节间的交叉引用
4. **图文并茂**: 合理使用图表、流程图增强可读性
5. **代码示例**: 提供实用代码示例帮助理解

## 编写规范

1. **语言**: 全部使用中文
2. **格式**: Markdown格式，支持Mermaid图表
3. **标题层级**: 使用1-6级标题
4. **代码块**: 使用```语言标识的代码块
5. **表格**: 使用Markdown表格格式
6. **链接**: 使用相对链接指向其他章节
