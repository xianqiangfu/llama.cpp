# 最佳实践

## 概述

本章总结了使用 llama.cpp 的最佳实践，包括性能优化、资源管理、部署方案和常见问题的解决方案。

## 1. 性能优化

### 1.1 模型选择策略

#### 根据硬件选择模型

| 硬件配置 | 推荐模型 | 量化级别 | 预期性能 |
|---------|---------|---------|----------|
| 8GB RAM, 无 GPU | LLaMA 3.2-1B | Q2_K | 5-10 tokens/s |
| 16GB RAM, 无 GPU | LLaMA 3.2-3B | Q4_K_M | 10-20 tokens/s |
| 16GB RAM, RTX 3060 | LLaMA 3.2-3B | Q4_K_M | 50-80 tokens/s |
| 32GB RAM, RTX 3090 | LLaMA 3.2-7B | Q4_K_M | 100-150 tokens/s |
| 64GB RAM, RTX 4090 | LLaMA 3.2-70B | Q4_K_M | 30-50 tokens/s |

#### 模型精度配置

```bash
# 高质量场景
./llama-cli -m model-Q5_K_M.gguf --cache-type-k Q8_0 --cache-type-v F16

# 平衡场景
./llama-cli -m model-Q4_K_M.gguf --cache-type-k Q4_K --cache-type-v Q4_K

# 高速度场景
./llama-cli -m model-Q4_0.gguf --cache-type-k Q4_0 --cache-type-v Q4_0
```



```python
import requests
import time
import matplotlib.pyplot as plt

def monitor_server(url="http://localhost:8080"):
```

```python
def filter_output(output_text):
    # 过滤敏感信息
    sensitive_patterns = [
        r'\b\d{3}-\d{2}-\d{4}\b',  # SSN
        r'\b\d{16}\b',             # 信用卡号
        r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b',  # 邮箱
    ]
    
    for pattern in sensitive_patterns:
        output_text = re.sub(pattern, '[REDACTED]', output_text)
    
    return output_text
```

#### 内存不足

```bash

# 解决方案:

./llama-cli -m model.gguf --cache-type-k Q4_K --cache-type-v Q4_K

./llama-cli -m model.gguf --batch-size 256

# 4. 使用更小的模型
./llama-cli -m model-Q4_K_M.gguf
```

```python
import time
import requests

def benchmark_generation(server_url, prompt, n_runs=10):
    times = []
    
    for i in range(n_runs):
        start = time.time()
        
        response = requests.post(
            f"{server_url}/v1/chat/completions",
            json={
                "model": "model",
                "messages": [{"role": "user", "content": prompt}],
                "max_tokens": 100,
            }
        )
        
        end = time.time()
        times.append(end - start)
    
    avg_time = sum(times) / len(times)
    min_time = min(times)
    max_time = max(times)
    
    print(f"Average: {avg_time:.2f}s, Min: {min_time:.2f}s, Max: {max_time:.2f}s")
```

## 7. 总结

llama.cpp 的最佳实践包括：

1. **性能优化**: 选择合适的模型和量化级别，配置 GPU 和批处理参数
2. **资源管理**: 优化内存、CPU 和磁盘 I/O 使用
3. **部署方案**: 支持单机、集群、容器化和云端部署
4. **监控维护**: 实时监控性能，自动恢复和备份
5. **安全防护**: 实施访问控制和数据安全措施
6. **故障排除**: 快速诊断和解决常见问题

通过遵循这些最佳实践，可以构建高效、稳定、安全的 LLM 推理服务。
