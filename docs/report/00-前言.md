## 技术背景

llama.cpp 是一个用 C/C++ 编写的轻量级大语言模型推理框架，由 Georgi Gerganov 于 2023 年 3 月首次发布。项目的主要目标是让普通用户和开发者能够在标准硬件上高效运行大语言模型。

### 核心特性

- **轻量高效**: 代码简洁，资源占用低
- **跨平台支持**: 支持 Windows、Linux、macOS 等主流操作系统
- **多硬件后端**: 支持 CPU、GPU 等多种硬件加速
- **丰富功能**: 支持量化、多模态、推测解码等高级功能
- **活跃社区**: 拥有庞大的开发者社区

### 技术栈

- **编程语言**: C/C++ (主要), Python (工具脚本)
- **构建系统**: CMake
- **核心库**: GGML (张量计算库)
- **模型格式**: GGUF (统一模型格式)
- **后端**: CUDA, Metal, Vulkan, OpenCL, SYCL, HIP 等

### 术语说明

- **LLM**: Large Language Model（大语言模型）
- **GGML**: GPT-Generated Model Language（张量计算库）
- **GGUF**: GPT-Generated Unified Format（模型格式）
- **KV Cache**: Key-Value Cache（键值缓存）
- **LoRA**: Low-Rank Adaptation（低秩适应）
- **MTP**: Multi-Token Prediction（多 Token 预测）
