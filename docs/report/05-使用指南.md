# 使用指南

## 概述

本章提供 llama.cpp 的详细使用指南，包括安装配置、基本使用、高级功能和常见用例。

## 1. 安装配置

### 1.1 系统要求

#### 最低要求

- **操作系统**: Windows 10+、Linux、macOS 11+
- **CPU**: 支持 SSE2 或 AVX2 的 x86_64 处理器，或 ARM64 处理器
- **内存**: 4GB RAM（8GB 推荐）
- **存储**: 10GB 可用空间（用于模型文件）
- **编译器**: GCC 7+、Clang 6+、MSVC 2019+

#### 推荐配置

- **CPU**: 支持 AVX512 或 AMX 的现代处理器
- **GPU**: NVIDIA RTX 30 系列、Apple M1/M2/M3、AMD RDNA3
- **内存**: 16GB+ RAM
- **存储**: SSD 推荐
- **网络**: 稳定的互联网连接（用于下载模型）

### 1.2 编译安装

#### Linux/macOS

```bash
# 克隆仓库
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp

# 基本编译
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j

# 启用 GPU 加速（根据硬件选择）
# CUDA (NVIDIA GPU)
cmake -B build -DGGML_CUDA=ON -DCMAKE_BUILD_TYPE=Release

# Metal (Apple Silicon)
cmake -B build -DGGML_METAL=ON -DCMAKE_BUILD_TYPE=Release

# Vulkan (跨平台)
cmake -B build -DGGML_VULKAN=ON -DCMAKE_BUILD_TYPE=Release
```

#### Windows

```cmd
# 使用 Visual Studio
cmake -B build -G "Visual Studio 17 2022" -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j

# 使用 MinGW
cmake -B build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j
```

### 2.3 批量推理

```cpp
// C++ 示例
#include "llama.h"

int main() {
    // 1. 初始化模型
    llama_model_params model_params = llama_model_default_params();
    llama_model * model = llama_load_model_from_file("model.gguf", model_params);
    
    // 2. 初始化上下文
    llama_context_params ctx_params = llama_context_default_params();
    ctx_params.n_ctx = 2048;  // 上下文窗口大小
    llama_context * ctx = llama_new_context_with_model(model, ctx_params);
    
    // 3. 编码输入
    std::string prompt = "Explain quantum computing";
    auto tokens = llama_tokenize(ctx, prompt, true);
    
    // 4. 批量处理
    llama_batch batch = llama_batch_init(tokens.size(), 0, 1);
    for (size_t i = 0; i < tokens.size(); i++) {
        batch.token[i] = tokens[i];
        batch.pos[i] = i;
        batch.seq_id[i][0] = 0;
        batch.logits[i] = (i == tokens.size() - 1);  // 最后一个 token 输出 logits
    }
    batch.n_tokens = tokens.size();
    
    // 5. 前向传播
    if (llama_decode(ctx, batch) != 0) {
        fprintf(stderr, "Failed to decode\n");
        return 1;
    }
    
    // 6. 采样生成
    auto * sampler = llama_sampler_chain_init({
        .no_perf = false,
        .seed = 1234,
        .n_prev = 64,
        .n_probs = 10,
        .min_keep = 1,
    });
    
    llama_sampler_chain_add(sampler, llama_sampler_init_top_k(50));
    llama_sampler_chain_add(sampler, llama_sampler_init_top_p(0.9, 1));
    llama_sampler_chain_add(sampler, llama_sampler_init_temp(0.8));
    llama_sampler_chain_add(sampler, llama_sampler_init_dist(1234));
    
    std::string output;
    for (int i = 0; i < 200; i++) {
        // 采样
        llama_token token = llama_sampler_sample(sampler, ctx, -1);
        
        // 检查是否结束
        if (token == llama_token_eos(model)) break;
        
        // 添加到输出
        output += llama_token_to_piece(ctx, token);
        
        // 准备下一个 token
        llama_batch single = llama_batch_init(1, 0, 1);
        single.token[0] = token;
        single.pos[0] = tokens.size() + i;
        single.seq_id[0][0] = 0;
        single.n_tokens = 1;
        
        if (llama_decode(ctx, single) != 0) {
            fprintf(stderr, "Failed to decode\n");
            break;
        }
    }
    
    printf("Output: %s\n", output.c_str());
    
    // 7. 清理资源
    llama_sampler_free(sampler);
    llama_free(ctx);
    llama_free_model(model);
    
    return 0;
}
```

## 3. 高级功能

```bash

  -m main-model.gguf \

  -p "Generate a long story"

  -m model.gguf \
  --spec-type ngram-mod \
  --spec-ngram-mod-n-match 24 \
  --spec-ngram-mod-n-max 64 \
```

### 3.3 KV Cache 量化

```bash
# KV Cache 量化配置
./llama-cli \
  -m model.gguf \
  --cache-type-k Q4_K \
  --cache-type-v Q4_K \
  -p "Long conversation example"

# 不同 KV 量化策略
./llama-cli \
  -m model.gguf \
  --cache-type-k Q8_0 \
  --cache-type-v F16 \
  -p "Balanced precision and memory"
```

### 3.4 语法约束

```bash
# JSON 输出约束
./llama-cli \
  -m model.gguf \
  -p "Generate a person profile" \
  --grammar 'root ::= obj obj ::= "{" ws string ws ":" ws person "}" person ::= "{" ws string ws ":" ws value ws "}" value ::= string | number | obj'

# 自定义语法
./llama-cli \
  -m model.gguf \
  -p "Generate a phone number" \
  --grammar 'root ::= "\([0-9]{3}\) [0-9]{3}-[0-9]{4}"'
```

### 3.5 LoRA 适配器

## 7. 故障排除

### 7.1 常见错误

#### 模型加载失败

```
Error: failed to load model from file: model.gguf
```

**解决方案：**
- 检查模型文件是否存在
- 验证文件完整性
- 检查内存是否足够

#### GPU 内存不足

```
Error: CUDA out of memory
```

**解决方案：**
- 减少层数到 GPU (`-ngl` 参数)
- 使用更小的模型
- 启用 KV Cache 量化
- 增加系统内存

#### 编译错误

```
Error: 'ggml.h' file not found
```

**解决方案：**
- 检查 CMake 配置
- 确保依赖已安装
- 清理构建缓存 (`rm -rf build`)

### 7.2 性能问题

#### 推理速度慢

**诊断步骤：**
1. 检查 GPU 利用率
2. 验证后端是否启用
3. 检查量化级别
4. 调整批处理参数

**优化建议：**
```bash
# 启用 GPU 加速
./llama-cli -m model.gguf -ngl 35

# 使用量化模型
./llama-cli -m model-Q4_K_M.gguf

# 启用推测解码
./llama-cli -m model.gguf --draft-model draft.gguf
```

#### 内存占用高

**优化建议：**
```bash
# 使用量化模型
./llama-cli -m model-Q4_K_M.gguf

# KV Cache 量化
./llama-cli -m model.gguf --cache-type-k Q4_K --cache-type-v Q4_K

# 减小上下文
./llama-cli -m model.gguf -c 2048
```
