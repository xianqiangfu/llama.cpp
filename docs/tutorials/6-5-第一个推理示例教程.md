## 第一个推理示例

### 基础文本生成

```bash
# 最简单的推理命令
llama-cli -m models/gemma-3-1b-it-Q4_K_M.gguf \
    -p "你好，请介绍一下你自己"

# 指定生成长度
llama-cli -m models/gemma-3-1b-it-Q4_K_M.gguf \
    -p "人工智能的未来" \
    -n 100

# 从文件读取提示词
echo "请写一首关于春天的诗" > prompt.txt
llama-cli -m models/gemma-3-1b-it-Q4_K_M.gguf \
    -f prompt.txt \
    -n 50
```

### 输出解析

**命令输出示例：**
```
你好！我是一个人工智能助手，可以帮助你回答问题、提供信息、进行创意写作等...

tokens per second = 23.45
```

**关键字段说明：**
- `tokens per second`: 生成速度（每秒生成的 token 数）
- `load time`: 模型加载时间
- `sample time`: 采样时间
- `prompt eval time`: 提示词处理时间

### 交互式模式

```bash
# 启用交互式模式（逐行输入）
```


### 多轮对话示例

```bash
#!/bin/bash
# multi-turn-conversation.sh

model="models/gemma-3-1b-it-Q4_K_M.gguf"

echo "=== 多轮对话示例 ==="
echo "提示：输入 'quit' 退出对话"

while true; do
    echo -n "用户: "
    read user_input
    
    if [ "$user_input" = "quit" ]; then
        break
    fi
    
    echo -n "助手: "
    llama-cli -m "$model" \
        -cnv \
        -p "$user_input" \
        -n 100 \
        --no-display-prompt
done

echo "对话结束"
```

## 实际应用

### 文本摘要

```bash
#!/bin/bash
# text-summarization.sh

input_file="$1"
model="models/gemma-3-1b-it-Q4_K_M.gguf"

if [ ! -f "$input_file" ]; then
    echo "错误：文件不存在 $input_file"
    exit 1

echo "=== 文本摘要 ==="

    -f "$input_file" \
    -p "请总结以上内容的要点：" \
```

### 翻译服务

```bash

# translation-service.sh
```

### 问答系统

```bash
#!/bin/bash
# qa-system.sh

model="models/gemma-3-1b-it-Q4_K_M.gguf"
context_file="qa_context.txt"

echo "=== 问答系统 ==="

# 加载上下文
if [ -f "$context_file" ]; then
    context=$(cat "$context_file")
    echo "已加载上下文：${context:0:100}..."
else
    context="没有预设上下文"
fi

echo "基于上下文：$context"
echo "输入问题（输入 'quit' 退出）："

while true; do
    echo -n "问题: "
    read question
    
    if [ "$question" = "quit" ]; then
        break
    fi
    
    echo "回答："
    llama-cli -m "$model" \
        -p "上下文：$context\n\n问题：$question\n\n请基于上下文回答问题：" \
        -n 300 \
        -c 8192
    echo ""
done
```

### 内存使用监控

```bash
#!/bin/bash
# memory-monitor.sh

model="models/gemma-3-1b-it-Q4_K_M.gguf"

echo "=== 内存使用监控 ==="

# 在后台运行推理
llama-cli -m "$model" \
    -p "长时间运行的内存测试" \
    -n 1000 \
    > /dev/null &

pid=$!

# 监控内存使用
while kill -0 $pid 2>/dev/null; do
    memory_info=$(ps -p $pid -o rss=)
    memory_mb=$((memory_info / 1024))
    
    echo "进程 $pid 的内存使用: ${memory_mb}MB"
    sleep 1
done
```

**解决方法：**
```bash
# 启用 GPU 加速

    -ngl 99 \
    -n 100

# 调整线程数

    -t 8 \
    -n 100
```
