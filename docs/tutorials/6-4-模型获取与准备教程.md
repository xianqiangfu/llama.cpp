## 模型来源

### 1. Hugging Face（推荐）

[Hugging Face](https://huggingface.co/) 是最受欢迎的模型分发平台，提供大量 llama.cpp 兼容的 GGUF 模型。

**优势：**

- 完善的模型卡和说明

## GGUF 格式介绍

### 什么是 GGUF？

GGUF (GPT-Generated Unified Format) 是 llama.cpp 使用的模型文件格式，具有以下特点：

- **高效压缩**：使用优化的二进制格式
- **快速加载**：支持内存映射和流式加载
- **跨平台**：在不同操作系统和架构上工作
- **元数据丰富**：包含模型配置、tokenizer 信息等

### GGUF 文件结构

```
model.gguf
├── 神经网络权重
├── 分词器数据
├── 模型配置
└── 元数据（训练参数、许可等）
```

### 支持的量化格式

| 格式 | 描述 | 适用场景 |
|------|------|---------|
| F16/F32 | 全精度 | 最高质量，需要大量内存 |
| Q8_0 | 8-bit 量化 | 平衡性能和质量 |
| Q5_K_M | 5-bit 混合量化 | 推荐用于大多数情况 |
| Q4_K_M | 4-bit 混合量化 | 小文件大小，良好性能 |
| Q3_K_M | 3-bit 混合量化 | 极小文件，适合边缘设备 |
| IQ4_XS | 4-bit 超量化 | 最小文件大小 |

## 模型下载

### 方法一：直接下载 GGUF 模型（推荐）

#### 1. 从 Hugging Face 下载

```bash
# 基础下载
wget https://huggingface.co/ggml-org/gemma-3-1b-it-GGUF/resolve/main/gemma-3-1b-it-Q4_K_M.gguf

# 或使用 curl
curl -L https://huggingface.co/ggml-org/gemma-3-1b-it-GGUF/resolve/main/gemma-3-1b-it-Q4_K_M.gguf -o gemma-3-1b-it-Q4_K_M.gguf

# 或使用 huggingface-cli
pip install huggingface-hub
huggingface-cli download ggml-org/gemma-3-1b-it-GGUF gemma-3-1b-it-Q4_K_M.gguf
```

#### 2. 组织模型文件

```bash
# 创建模型目录结构
mkdir -p ~/llama.cpp/models/gemma-3-1b-it
mkdir -p ~/llama.cpp/models/llama-3-8b-instruct

# 移动文件
mv gemma-3-1b-it-Q4_K_M.gguf ~/llama.cpp/models/gemma-3-1b-it/

# 创建符号链接（可选）
cd ~/llama.cpp/models
ln -s gemma-3-1b-it/gemma-3-1b-it-Q4_K_M.gguf current-model.gguf
```

### 方法二：使用 llama-cli 直接下载

```bash
# 下载并立即运行模型
llama-cli -hf ggml-org/gemma-3-1b-it-GGUF

# 指定量化级别下载
llama-cli -hf ggml-org/gemma-3-1b-it-GGUF:Q4_K_M

# 下载多模态模型（会自动下载 mmproj 文件）
llama-cli -hf ggml-org/GLM-4.7-Flash-GGUF:Q4_K_M

# 下载到特定目录
llama-cli -hf ggml-org/gemma-3-1b-it-GGUF \
    -m models/gemma-3-1b-it/gemma-3-1b-it-Q4_K_M.gguf
```

### 方法三：批量下载模型

```bash
#!/bin/bash
# 批量下载脚本

models=(
    "ggml-org/gemma-3-1b-it-GGUF:Q4_K_M"
    "ggml-org/GLM-4.7-Flash-GGUF:Q4_K_M"
    "meta-llama/Llama-3.1-8B-Instruct-GGUF:Q4_K_M"
)

for model in "${models[@]}"; do
    echo "下载模型: $model"
    llama-cli -hf "$model"
done

echo "所有模型下载完成！"
```

### 验证下载

```bash
# 检查文件完整性
md5sum gemma-3-1b-it-Q4_K_M.gguf
sha256sum gemma-3-1b-it-Q4_K_M.gguf

# 检查文件大小
ls -lh gemma-3-1b-it-Q4_K_M.gguf

# 尝试加载模型
llama-cli -m gemma-3-1b-it-Q4_K_M.gguf -n 1
```

## 模型转换

### 从 Hugging Face 模型转换

#### 1. 安装依赖

```bash
# 安装 Python 依赖
pip install -r requirements.txt

# 或单独安装必需的包
pip install torch transformers sentencepiece numpy
```

#### 2. 转换模型

```bash
# 基础转换
python3 convert_hf_to_gguf.py --model /path/to/hf/model \
    --outfile model.gguf \
    --vocab-type auto

# 转换 LLaMA 模型
python3 convert_llama_ggml_to_gguf.py \
    --model /path/to/llama_model.ggml \
    --outfile model.gguf

# 转换 LoRA 适配器
python3 convert_lora_to_gguf.py \
    --base-model /path/to/base_model.gguf \
    --lora-model /path/to/lora_adapter \
    --outfile model-lora.gguf
```

### 转换示例

#### 转换 Meta LLaMA 3

```bash
# 1. 下载原始模型
git clone https://huggingface.co/meta-llama/Llama-3.1-8B-Instruct
cd Llama-3.1-8B-Instruct

# 2. 转换为 GGUF
python3 /path/to/llama.cpp/convert_hf_to_gguf.py \
    --model . \
    --outfile llama-3.1-8b-instruct-f16.gguf \
    --vocab-type auto

# 3. 验证转换
llama-cli -m llama-3.1-8b-instruct-f16.gguf -n 10
```

#### 转换 Qwen 模型

```bash
# 1. 下载 Qwen 模型
git clone https://huggingface.co/Qwen/Qwen1.5-14B-Chat
cd Qwen1.5-14B-Chat

# 2. 转换为 GGUF
python3 /path/to/llama.cpp/convert_hf_to_gguf.py \
    --model . \
    --outfile qwen1.5-14b-chat-f16.gguf \
    --vocab-type auto
```

### 转换选项

```bash
# 指定输出文件名
python3 convert_hf_to_gguf.py \
    --model /path/to/model \
    --outfile output.gguf

# 控制输出精度
python3 convert_hf_to_gguf.py \
    --model /path/to/model \
    --outfile output.gguf \
    --outtype f16  # f16, q8_0

# 使用特定分词器
python3 convert_hf_to_gguf.py \
    --model /path/to/model \
    --vocab-type spm  # auto, spm, bpe
```

## 模型量化

### 基础量化

```bash
# 量化为 Q4_K_M 格式（推荐）
./build/bin/llama-quantize \
    model-f16.gguf \
    model-Q4_K_M.gguf \
    Q4_K_M

# 量化为 Q5_K_M 格式
./build/bin/llama-quantize \
    model-f16.gguf \
    model-Q5_K_M.gguf \
    Q5_K_M

# 量化为 Q8_0 格式
./build/bin/llama-quantize \
    model-f16.gguf \
    model-Q8_0.gguf \
    Q8_0
```

### 使用重要性矩阵（Imatrix）优化量化

```bash
# 1. 生成重要性矩阵
./build/bin/llama-imatrix \
    -m model-f16.gguf \
    -f calibration_text.txt \
    -o imatrix.dat

# 2. 使用重要性矩阵进行量化
./build/bin/llama-quantize \
    --imatrix imatrix.dat \
    model-f16.gguf \
    model-Q4_K_M-imatrix.gguf \
    Q4_K_M
```

### 高级量化选项

```bash
# 保持输出层未量化
./build/bin/llama-quantize \
    --leave-output-tensor \
    model-f16.gguf \
    model-Q4_K_M.gguf \
    Q4_K_M

# 使用纯量化（所有张量相同精度）
./build/bin/llama-quantize \
    --pure \
    model-f16.gguf \
    model-Q4_K_M.gguf \
    Q4_K_M

# 允许重新量化（从已量化模型）
./build/bin/llama-quantize \
    --allow-requantize \
    model-Q4_K_M.gguf \
    model-Q3_K_M.gguf \
    Q3_K_M

# 指定线程数
./build/bin/llama-quantize \
    model-f16.gguf \
    model-Q4_K_M.gguf \
    Q4_K_M \
    8
```

### 批量量化

```bash
#!/bin/bash
# 批量量化脚本

models=(
    "model1-f16.gguf"
    "model2-f16.gguf"
    "model3-f16.gguf"
)

for model in "${models[@]}"; do
    echo "量化模型: $model"
    
    ./build/bin/llama-quantize \
        "$model" \
        "${model%.gguf}-Q4_K_M.gguf" \
        Q4_K_M \
        8
done

echo "所有模型量化完成！"
```

## 模型选择

### 硬件要求

#### 内存需求

| 模型大小 | F16 | Q8_0 | Q5_K_M | Q4_K_M | Q3_K_M |
|----------|-----|------|--------|--------|--------|
| 3B      | 6GB | 3.5GB | 2.5GB | 2GB | 1.5GB |
| 7B      | 14GB | 7.5GB | 5GB | 4GB | 3GB |
| 13B     | 26GB | 13.5GB | 9GB | 7GB | 5.5GB |
| 30B     | 60GB | 30GB | 20GB | 15GB | 11GB |

#### GPU 显存需求

| 模型大小 | Q4_K_M | Q5_K_M | Q8_0 | F16 |
|----------|---------|--------|------|-----|
| 7B      | 5GB | 6GB | 9GB | 14GB |
| 13B     | 8GB | 10GB | 15GB | 26GB |
| 30B     | 18GB | 22GB | 33GB | 60GB |

### 性能考虑

**量化格式比较：**

| 格式 | 质量损失 | 速度提升 | 文件大小 | 推荐场景 |
|------|---------|---------|---------|---------|
| F16 | 无 | 基准 | 100% | 最高质量需求 |
| Q8_0 | 极小 | 1.2x | 50% | 高质量需求 |
| Q5_K_M | 小 | 1.5x | 35% | 一般用途（推荐） |
| Q4_K_M | 小 | 1.8x | 28% | 边缘设备（推荐） |
| Q3_K_M | 中等 | 2.0x | 22% | 极端受限环境 |

### 推荐配置

**入门级（4-8GB RAM）：**
- 模型：3B-7B 参数
- 量化：Q4_K_M 或 Q5_K_M
- 后端：CPU 或集成 GPU

**主流级（16GB RAM，8GB+ VRAM）：**
- 模型：7B-13B 参数
- 量化：Q4_K_M 或 Q5_K_M
- 后端：CUDA 或 Metal

**高级级（32GB+ RAM，16GB+ VRAM）：**
- 模型：13B-30B 参数
- 量化：Q4_K_M、Q5_K_M 或 Q8_0
- 后端：多 GPU 设置

## 模型管理

### 目录组织

```bash
# 推荐的目录结构
~/llama.cpp/
├── models/
│   ├── base/              # 原始模型
│   ├── quantized/         # 量化模型
│   └── favorites/          # 常用模型
├── scripts/             # 管理脚本
└── configs/             # 配置文件
```

### 符号链接管理

```bash
# 创建当前模型链接
ln -s models/quantized/gemma-3-1b-it-Q4_K_M.gguf models/current.gguf

# 切换模型
rm models/current.gguf
ln -s models/quantized/llama-3-8b-instruct-Q4_K_M.gguf models/current.gguf

# 验证模型
llama-cli -m models/current.gguf -n 5
```

### 模型信息脚本

```bash
#!/bin/bash
# show-model-info.sh

model_file="$1"

if [ -z "$model_file" ]; then
    echo "使用方法: $0 <model.gguf>"
    exit 1
fi

echo "=== 模型信息 ==="
echo "文件: $model_file"
echo "大小: $(du -h "$model_file")"

# 获取模型信息
llama-cli -m "$model_file" -n 1 2>&1 | grep -E "(n_ctx_train|n_embd|n_params)" || echo "无法读取模型信息"
```

### 缓存管理

```bash
# 清理 Hugging Face 缓存
llama-cli --cache-list

# 删除特定模型缓存
rm -rf ~/.cache/huggingface/hub/models--ggml-org--*

# 重新下载模型
llama-cli -hf ggml-org/gemma-3-1b-it-GGUF --offline
```

## 故障排查

### 常见问题

#### Q1: 下载速度慢或中断

**解决方案：**
```bash
# 使用镜像站点
export HF_ENDPOINT=https://hf-mirror.com
llama-cli -hf ggml-org/gemma-3-1b-it-GGUF

# 使用断点续传
wget -c https://huggingface.co/ggml-org/gemma-3-1b-it-GGUF/resolve/main/gemma-3-1b-it-Q4_K_M.gguf

# 使用 aria2c 多线程下载
aria2c -x 16 -s 8 https://huggingface.co/.../model.gguf
```

#### Q2: 模型加载失败

**解决方案：**
```bash
# 检查文件完整性
md5sum model.gguf

# 检查内存可用性
free -h  # Linux
vm_stat     # macOS

# 尝试减少上下文大小
llama-cli -m model.gguf -c 2048

# 使用内存映射禁用
llama-cli -m model.gguf --no-mmap
```

#### Q3: 量化质量差

**解决方案：**
```bash
# 使用重要性矩阵
./build/bin/llama-imatrix -m model.gguf -f calibration.txt -o imatrix.dat
./build/bin/llama-quantize --imatrix imatrix.dat model.gguf model-quantized.gguf Q4_K_M

# 使用更高的量化级别
./build/bin/llama-quantize model.gguf model-quantized.gguf Q5_K_M

# 保持输出层未量化
./build/bin/llama-quantize --leave-output-tensor model.gguf model-quantized.gguf Q4_K_M
```

#### Q4: 多模态模型问题

**解决方案：**
```bash
# 确保下载了 mmproj 文件
llama-cli -hf ggml-org/GLM-4.7-Flash-GGUF:Q4_K_M

# 手动指定 mmproj 文件
llama-cli -m model.gguf --mmproj mmproj.gguf

# 验证多模态支持
llama-cli -m model.gguf --list-devices | grep -i multimodal
```

### 日志和调试

## 最佳实践

### 1. 模型选择

- 从小模型开始，验证性能后再升级
- 使用与你的用例匹配的模型
- 考虑社区支持和更新频率

### 2. 量化策略

- 为生产环境使用 Q4_K_M 或 Q5_K_M
- 为高质量需求使用 Q8_0
- 使用重要性矩阵进行量化以获得更好质量

### 3. 存储管理

- 将模型存储在高速存储（SSD）上
- 保持合理的目录结构
- 定期清理不必要的文件

### 4. 版本控制

- 记录使用的模型版本
- 保存原始模型文件
- 测试新版本后再部署
