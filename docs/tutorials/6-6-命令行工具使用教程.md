## 工具概述

### llama-cli 功能

llama-cli 是 llama.cpp 的主要命令行工具，提供以下功能：

- **文本生成**：从提示词生成连续文本
- **对话模式**：交互式多轮对话
- **代码生成**：支持各种编程语言
- **多模态支持**：图像、音频处理
- **性能监控**：实时性能统计
- **批量处理**：文件批量处理

### 工具架构

```bash
llama-cli
├── 模型加载器
├── 分词器
├── 推理引擎
├── 采样器
└── 输出处理器
```

## 基本用法

### 命令格式

```bash
llama-cli [选项] -m <模型文件> -p <提示词>
```

### 基础示例

```bash
# 最简单的文本生成
llama-cli -m model.gguf -p "你好，请介绍一下你自己"

# 指定生成长度
llama-cli -m model.gguf -p "人工智能的未来" -n 100

# 从文件读取提示词
llama-cli -m model.gguf -f prompt.txt -n 50

# 使用环境变量
export LLAMA_ARG_MODEL="model.gguf"
llama-cli -p "测试文本" -n 20
```

### 参数说明

**核心参数：**
- `-m, --model`：模型文件路径
- `-p, --prompt`：提示词文本
- `-f, --file`：从文件读取提示词
- `-n, --n-predict`：生成的 token 数量
- `-c, --ctx-size`：上下文大小

**系统参数：**
- `-t, --threads`：线程数
- `-b, --batch-size`：批处理大小
- `--temp, --temperature`：温度参数
- `--top-k`：Top-k 采样
- `--top-p`：Top-p 采样

## 采样控制

```bash

llama-cli -m model.gguf -p "生成代码" \
    --temp 0.2 -n 50

# 中温（平衡）
llama-cli -m model.gguf -p "生成文本" \
    --temp 0.7 -n 50

# 高温（更创意）
```

### Top-k 和 Top-p

```bash

llama-cli -m model.gguf -p "技术内容" \
    --top-k 40 -n 50

    --top-p 0.95 -n 50

# 结合使用
llama-cli -m model.gguf -p "混合采样" \
    --top-k 30 --top-p 0.9 -n 50
```

## 脚本化使用

### 批量处理

```bash
#!/bin/bash
# batch-process.sh

model="models/gemma-3-1b-it-Q4_K_M.gguf"
input_dir="prompts"
output_dir="results"

mkdir -p "$output_dir"

for prompt_file in "$input_dir"/*.txt; do
    filename=$(basename "$prompt_file" .txt)
    output_file="$output_dir/$filename.txt"
    
    echo "处理: $filename"
    
    llama-cli -m "$model" \
        -f "$prompt_file" \
        -n 200 \
        -c 4096 \
        > "$output_file"
    
    echo "完成: $output_file"
done

echo "批量处理完成"
```

### 错误处理

```bash
#!/bin/bash
# error-handler.sh

model="models/gemma-3-1b-it-Q4_K_M.gguf"
log_file="llama-cli.log"

# 错误处理函数
run_llama() {
    local prompt="$1"
    local max_tokens="${2:-100}"
    
    # 检查模型是否存在
    if [ ! -f "$model" ]; then
        echo "错误：模型文件不存在: $model" >&2
        return 1
    fi
    
    # 运行推理并记录日志
    if llama-cli -m "$model" \
        -p "$prompt" \
        -n "$max_tokens" \
        2>&1 | tee -a "$log_file"; then
        return 0
    else
        echo "错误：推理失败" >&2
        return 1
    fi
}

# 重试机制
run_with_retry() {
    local max_attempts=3
    local attempt=1
    
    while [ $attempt -le $max_attempts ]; do
        echo "尝试 $attempt/$max_attempts"
        
        if run_llama "重试测试" 50; then
            echo "成功！"
            return 0
        fi
        
        ((attempt++))
        sleep 2
    done
    
    echo "所有尝试都失败" >&2
    return 1
}

# 使用错误处理
if run_with_retry; then
    echo "操作成功完成"
else
    echo "操作失败，请检查日志: $log_file"
    exit 1
fi
```
