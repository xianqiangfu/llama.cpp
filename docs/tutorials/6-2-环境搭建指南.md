## 系统要求

### 最低要求

- **操作系统**: Windows 10+、Linux（主流发行版）、macOS 10.15+
- **处理器**: 支持现代指令集的 CPU（AVX2 推荐）
- **内存**: 至少 4GB RAM（8GB+ 推荐）
- **存储**: 10GB 可用空间（用于模型文件）
- **编译器**: C++17 兼容编译器（如果从源码构建）

### 推荐配置

- **处理器**: 多核 CPU（8核+），支持 AVX2/AVX512
- **内存**: 16GB+ RAM
- **存储**: SSD（推荐）或高速 HDD
- **GPU**: NVIDIA RTX 系列、AMD Radeon RX 系列、Apple Silicon（M1/M2/M3）
- **编译器**: GCC 9+、Clang 10+、MSVC 2019+

## 依赖管理

### 基础依赖

所有平台都需要的基础工具：

```bash
# Git（用于克隆仓库）
# 下载: https://git-scm.com/downloads

# CMake（用于构建）
# 下载: https://cmake.org/download/

# Python 3.8+（用于模型转换等脚本）
```

### 可选依赖

根据你的使用场景选择：

#### GPU 加速

- **NVIDIA GPU**: CUDA Toolkit 11.8+
- **AMD GPU**: ROCm 5.0+
- **Apple Silicon**: Metal 框架（系统自带）
- **Intel GPU**: oneAPI Base Toolkit

#### BLAS 加速

- **OpenBLAS**: 开源 BLAS 库
- **Intel MKL**: Intel 数学内核库
- **BLIS**: 框架无关 BLAS 实现

#### 其他功能

- **OpenSSL 3**: 用于 SSL/TLS 支持
- **Vulkan SDK**: 用于 Vulkan 后端
- **LLVM/Clang**: 用于某些后端编译

## Windows 环境搭建

### 方式一：使用预构建二进制文件（推荐初学者）

1. **下载预构建版本**

   访问 [GitHub Releases](https://github.com/ggml-org/llama.cpp/releases) 并下载适合你系统的版本：
   - `llama-cli-win-x86_64.zip`（64 位 Intel/AMD）
   - `llama-cli-win-arm64.zip`（ARM64）

2. **解压和配置**

   ```powershell
   # 解压文件
   Expand-Archive -Path llama-cli-win-x86_64.zip -DestinationPath C:\llama.cpp

   # 添加到 PATH（可选）
   $env:Path += ";C:\llama.cpp\bin"
   [Environment]::SetEnvironmentVariable("Path", $env:Path, "User")
   ```

3. **验证安装**

   ```powershell
   C:\llama.cpp\bin\llama-cli.exe --version
   ```

### 方式二：使用 Visual Studio 构建

1. **安装 Visual Studio 2022**

   下载 [Visual Studio 2022 Community](https://visualstudio.microsoft.com/vs/community/)

   在安装时选择：
   - Desktop development with C++
   - CMake tools for Windows
   - Git for Windows
   - C++ Clang Compiler for Windows

2. **克隆并构建项目**

   ```powershell
   # 克隆仓库
   git clone https://github.com/ggml-org/llama.cpp
   cd llama.cpp

   # 构建（使用 Developer Command Prompt for VS 2022）
   cmake -B build -G "Visual Studio 17 2022" -A x64
   cmake --build build --config Release

   # 或者使用简单的 CPU 构建
   cmake -B build
   cmake --build build --config Release
   ```

3. **测试构建结果**

   ```powershell
   .\build\bin\Release\llama-cli.exe --version
   ```

### 方式三：使用 w64devkit（轻量级）

1. **下载和设置 w64devkit**

   ```powershell
   # 下载 w64devkit
   # https://github.com/skeeto/w64devkit/releases

   # 解压到目录
   # 运行 w64devkit.exe
   ```

2. **在 w64devkit 中构建**

   ```bash
   # 在 w64devkit 环境中
   git clone https://github.com/ggml-org/llama.cpp
   cd llama.cpp

   cmake -B build -G Ninja
   cmake --build build --config Release
   ```

### Windows CUDA 支持

1. **安装 CUDA Toolkit**

   - 下载 [CUDA Toolkit 11.8+](https://developer.nvidia.com/cuda-downloads)
   - 运行安装程序，选择自定义安装
   - 确保包含 "CUDA Development Tools" 和 "CUDA Runtime"

2. **构建 CUDA 版本**

   ```powershell
   cmake -B build -DGGML_CUDA=ON
   cmake --build build --config Release
   ```

3. **验证 CUDA 支持**

   ```powershell
   .\build\bin\Release\llama-cli.exe --list-devices
   ```

## Linux 环境搭建

### Ubuntu/Debian

```bash
# 更新系统
sudo apt update && sudo apt upgrade -y

# 安装基础依赖
sudo apt install -y \
    git \
    cmake \
    build-essential \
    python3 \
    python3-pip

# 可选：安装 BLAS 加速
sudo apt install -y libopenblas-dev

# 可选：安装 CUDA 支持
# 参考 NVIDIA 官方文档安装 CUDA Toolkit
```

### Fedora/RHEL/CentOS

```bash
# 安装基础依赖
sudo dnf install -y \
    git \
    cmake \
    gcc \
    gcc-c++ \
    make \
    python3 \
    python3-pip

# 可选：安装 BLAS 加速
sudo dnf install -y openblas-devel

# 可选：安装 CUDA 支持
# 参考 NVIDIA 官方文档安装 CUDA Toolkit
```

### Arch Linux

```bash
# 安装基础依赖
sudo pacman -S --needed \
    git \
    cmake \
    base-devel \
    python \
    python-pip

# 可选：安装 BLAS 加速
sudo pacman -S openblas

# 可选：安装 CUDA 支持
# 参考 NVIDIA AUR 包
```

### 构建 llama.cpp

```bash
# 克隆仓库
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp

# 基础 CPU 构建
cmake -B build
cmake --build build --config Release -j$(nproc)

# 带 CUDA 支持的构建
cmake -B build -DGGML_CUDA=ON
cmake --build build --config Release -j$(nproc)

# 带多种后端的构建
cmake -B build \
    -DGGML_CUDA=ON \
    -DGGML_BLAS=ON \
    -DGGML_BLAS_VENDOR=OpenBLAS
cmake --build build --config Release -j$(nproc)
```

### 安装到系统

```bash
# 可选：安装到系统目录
sudo cmake --install build --prefix /usr/local

# 或设置 PATH
echo 'export PATH="$HOME/llama.cpp/build/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

## macOS 环境搭建

### 使用 Homebrew（推荐）

```bash
# 安装 Homebrew（如果尚未安装）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装依赖
brew install git cmake python3

# 可选：安装 OpenBLAS
brew install openblas
```

### 从源码构建

```bash
# 克隆仓库
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp

# 构建（Metal 支持默认启用）
cmake -B build
cmake --build build --config Release -j$(sysctl -n hw.ncpu)

# 验证 Metal 支持
./build/bin/llama-cli --list-devices
```

### Apple Silicon 特定配置

```bash
# 对于 Apple Silicon，Metal 是默认后端
# 可以显式启用特定优化

cmake -B build \
    -DCMAKE_OSX_ARCHITECTURES=arm64 \
    -DGGML_METAL=ON
cmake --build build --config Release
```

### 通用二进制支持（可选）

```bash
# 构建 Intel 和 ARM 通用二进制文件
cmake -B build \
    -DCMAKE_OSX_ARCHITECTURES="arm64;x86_64" \
    -DGGML_METAL=ON
cmake --build build --config Release
```

## Docker 环境

### 使用官方 Docker 镜像

```bash
# 拉取服务器镜像
docker pull ghcr.io/ggml-org/llama.cpp:server

# 拉带 CUDA 支持的镜像
docker pull ghcr.io/ggml-org/llama.cpp:server-cuda

# 运行容器
docker run -d \
  --name llama-server \
  -p 8080:8080 \
  -v $(pwd)/models:/models \
  ghcr.io/ggml-org/llama.cpp:server \
  -m models/gemma-3-1b-it-GGUF/*.gguf
```

### 从 Dockerfile 构建

```bash
# 克隆仓库
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp

# 构建 Docker 镜像
docker build -t llama-cpp:local .

# 运行自定义镜像
docker run -p 8080:8080 \
  -v $(pwd)/models:/models \
  llama-cpp:local \
  -m models/model.gguf
```

### GPU 支持（NVIDIA）

```bash
# 安装 NVIDIA Container Toolkit
# 参考: https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/install-guide.html

# 运行带 GPU 支持的容器
docker run -d \
  --gpus all \
  --name llama-gpu-server \
  -p 8080:8080 \
  -v $(pwd)/models:/models \
  ghcr.io/ggml-org/llama.cpp:server-cuda \
  -m models/model.gguf \
  -ngl 99
```

### 多平台构建

```bash
# 为不同平台构建
docker buildx build --platform linux/amd64,linux/arm64 -t llama-cpp:multi .

# 使用 buildx 运行
docker buildx build --platform linux/arm64 -t llama-cpp:arm64 .
```

## 故障排查

### 常见问题

#### 1. CMake 找不到编译器

**症状**：
```
CMake Error: CMAKE_C_COMPILER not set
```

**解决方案**：
```bash
# Linux/macOS
export CC=gcc
export CXX=g++
cmake -B build

# Windows (Visual Studio)
# 使用 Developer Command Prompt
```

#### 2. GPU 设备未找到

**症状**：
```
ggml_cuda_init: GGML_CUDA_FORCE_MMQ: not supported
CUDA not detected
```

**解决方案**：
```bash
# 检查 CUDA 安装
nvidia-smi

# 检查环境变量
echo $CUDA_HOME
echo $LD_LIBRARY_PATH

# 重新构建并启用 CUDA
cmake -B build -DGGML_CUDA=ON
cmake --build build --config Release
```

#### 3. 内存不足错误

**症状**：
```
out of memory
```

**解决方案**：
```bash
# 减少上下文大小
llama-cli -m model.gguf -c 2048

# 减少批处理大小
llama-cli -m model.gguf -b 512

# 使用更小的模型或更高的量化
```

#### 4. Python 依赖问题

**症状**：
```
ModuleNotFoundError: No module named 'xxx'
```

**解决方案**：
```bash
# 安装 Python 依赖
pip install -r requirements.txt

# 或逐个安装
pip install numpy scipy transformers sentencepiece
```

#### 5. 编译错误

**症状**：
```
error: 'xxx' was not declared in this scope
```

**解决方案**：
```bash
# 清理构建目录
rm -rf build
cmake -B build
cmake --build build --config Release

# 检查编译器版本
gcc --version
clang --version
```

### 日志和调试

```bash
# 启用详细日志
llama-cli -m model.gguf -v

# 设置日志级别
export LLAMA_LOG_VERBOSITY=4  # Debug 级别

# 检查系统资源
htop          # Linux
top           # macOS/Linux
taskmgr       # Windows
```

1. **查看日志**：详细日志通常包含错误信息

## 环境配置最佳实践

### 1. 目录结构

```bash
~/llama.cpp/
├── build/              # 构建输出
├── models/             # 模型文件
├── scripts/            # 自定义脚本
└── logs/               # 日志文件
```

### 2. 环境变量

```bash
# 添加到 ~/.bashrc 或 ~/.zshrc
export LLAMA_CPP_HOME="$HOME/llama.cpp"
export PATH="$LLAMA_CPP_HOME/build/bin:$PATH"
export MODELS_PATH="$LLAMA_CPP_HOME/models"

# CUDA 环境变量（如果使用 CUDA）
export CUDA_HOME="/usr/local/cuda"
export LD_LIBRARY_PATH="$CUDA_HOME/lib64:$LD_LIBRARY_PATH"
```

### 3. 自动化脚本

```bash
# 创建启动脚本 ~/bin/llama-cli
#!/bin/bash
llama-cli -m "$MODELS_PATH/model.gguf" "$@"
```

### 4. 版本管理

```bash
# 使用 Git 标签管理版本
git tag -a v1.0.0 -m "First release"
git push origin v1.0.0

# 更新到最新版本
git pull origin master
```
