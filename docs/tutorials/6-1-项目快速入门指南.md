# llama.cpp 项目快速入门指南

## 什么是 llama.cpp

llama.cpp 是一个纯 C/C++ 实现的大语言模型推理引擎，旨在以最小的设置在广泛的硬件（本地和云端）上实现最先进的性能。

### 核心特性

- **纯 C/C++ 实现**：无任何外部依赖
- **跨平台支持**：支持 Windows、Linux、macOS 等多种操作系统
- **多硬件后端**：支持 CPU、NVIDIA GPU、AMD GPU、Apple Silicon、Intel GPU 等
- **高效量化**：支持 1.5-bit 到 8-bit 的整数量化，减少内存使用并提高推理速度
- **完整工具链**：提供命令行工具、服务器、量化工具等

### 支持的模型

llama.cpp 支持广泛的模型系列，包括：

**文本模型：**
- LLaMA 系列（1、2、3）
- Mistral、Mixtral
- Qwen 系列
- Phi 系列
- Gemma 系列
- 以及更多...

**多模态模型：**
- LLaVA 系列
- Mini CPM
- Yi-VL
- 以及更多...

## 快速开始

### 方式一：使用预构建版本（推荐初学者）

#### Windows

1. 从 [GitHub Releases](https://github.com/ggml-org/llama.cpp/releases) 下载最新的 Windows 预构建二进制文件
2. 解压到本地目录
3. 运行可执行文件

```powershell
# 下载模型文件
llama-cli.exe -hf ggml-org/gemma-3-1b-it-GGUF

# 开始对话
llama-cli.exe -m models\gemma-3-1b-it-GGUF\*.gguf -cnv
```

#### Linux/macOS

```bash
# 使用 Homebrew 安装（macOS）
brew install llama.cpp

# 或从 Releases 下载预构建版本
wget https://github.com/ggml-org/llama.cpp/releases/download/bXXXX/llama-cli-linux-x86_64.zip
unzip llama-cli-linux-x86_64.zip
chmod +x llama-cli

# 下载并运行模型
./llama-cli -hf ggml-org/gemma-3-1b-it-GGUF -cnv
```

### 方式二：从源码构建

```bash
# 克隆仓库
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp

# 构建
cmake -B build
cmake --build build --config Release

# 运行
./build/bin/llama-cli -hf ggml-org/gemma-3-1b-it-GGUF -cnv
```

### 方式三：使用 Docker

```bash
# 拉取官方镜像
docker pull ghcr.io/ggml-org/llama.cpp:server

# 运行容器
docker run -p 8080:8080 \
  -v $(pwd)/models:/models \
  ghcr.io/ggml-org/llama.cpp:server \
  -m models/gemma-3-1b-it-GGUF/*.gguf
```

## 基本使用

### 命令行工具（llama-cli）

```bash
# 基本使用
llama-cli -m model.gguf -p "你好，请介绍一下你自己"

# 对话模式
llama-cli -m model.gguf -cnv

# 使用 Hugging Face 模型
llama-cli -hf ggml-org/gemma-3-1b-it-GGUF -cnv
```

### HTTP 服务器（llama-server）

```bash
# 启动服务器
llama-server -m model.gguf --port 8080

# 访问 Web UI
# 浏览器打开: http://localhost:8080

# 使用 API 调用
curl http://localhost:8080/completion \
  -H "Content-Type: application/json" \
  -d '{"prompt": "你好", "n_predict": 128}'
```

## 常用命令

### 模型管理

```bash
# 从 Hugging Face 下载模型
llama-cli -hf ggml-org/gemma-3-1b-it-GGUF

# 查看缓存中的模型列表
llama-cli --cache-list

# 检查模型健康状态
curl http://localhost:8080/health
```

### 性能优化

```bash
# 使用 GPU 加速
llama-cli -m model.gguf -ngl 99 -cnv

# 设置上下文大小
llama-cli -m model.gguf -c 8192 -cnv

# 设置线程数
llama-cli -m model.gguf -t 8 -cnv
```

### 调试与监控

```bash
# 查看可用设备
llama-cli --list-devices

# 显示详细日志
llama-cli -m model.gguf -v

# 查看服务器状态
curl http://localhost:8080/props
curl http://localhost:8080/slots
```

## 常见问题

### Q: 我需要什么样的硬件才能运行 llama.cpp？

**A**: 最低要求：
- CPU: 任意现代 CPU
- 内存: 根据模型大小，至少需要模型文件大小的 1.5 倍
- 存储: 模型文件存储空间

推荐配置：
- GPU: NVIDIA GPU（CUDA）、AMD GPU（ROCm）、Apple Silicon（Metal）
- 内存: 16GB 或更多
- 存储: SSD 以获得更快的模型加载速度

### Q: 哪种量化格式最适合我的用例？

**A**: 常用量化格式推荐：
- **Q4_K_M**: 平衡性能和质量，推荐用于大多数情况
- **Q5_K_M**: 更高质量，但文件更大
- **Q8_0**: 最高质量，推理较慢
- **IQ2_XXS/IQ3_XXS**: 极小文件大小，适合边缘设备

### Q: 如何选择合适的模型大小？

**A**: 根据你的硬件配置：
- **4GB-8GB 内存**: 3B-7B 参数的模型
- **16GB 内存**: 7B-13B 参数的模型
- **32GB+ 内存**: 13B-70B 参数的模型
- **GPU**: 可以加载更大的模型到显存中

### Q: llama.cpp 与其他推理框架有什么区别？

**A**: 主要优势：
- 纯 C/C++ 实现，无 Python 依赖
- 支持广泛的硬件后端
- 高效的量化实现
- 轻量级，易于部署
- 活跃的社区和持续的更新
