## 构建前准备

### 获取源代码

```bash
# 克隆主仓库
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp

# 或克隆特定分支
git clone -b bXXXX https://github.com/ggml-org/llama.cpp
cd llama.cpp

# 或使用深度克隆（包含子模块）
git clone --recursive https://github.com/ggml-org/llama.cpp
```

### 检查依赖

```bash
# 检查 CMake 版本（需要 3.20+）
cmake --version

# 检查编译器
gcc --version    # GCC
clang --version  # Clang
cl               # MSVC (Windows)

# 检查 Python（用于模型转换脚本）
python3 --version
pip3 --version
```

## 基础构建流程

### Linux/macOS（Unix Makefiles）

```bash
# 1. 配置构建目录
cmake -B build

# 2. 编译
cmake --build build --config Release

# 3. 安装（可选）
cmake --install build --prefix /usr/local
```

### Windows（Visual Studio）

```powershell
# 1. 配置构建目录
cmake -B build -G "Visual Studio 17 2022" -A x64

# 2. 编译
cmake --build build --config Release

# 3. 或使用 Ninja 生成器
cmake -B build -G Ninja
cmake --build build --config Release
```

### Windows（MinGW/MSYS2）

```bash
# 1. 配置构建目录
cmake -B build -G "Unix Makefiles"

# 2. 编译
cmake --build build --config Release
```

### 并行编译优化

```bash
# 使用所有可用核心
cmake --build build --config Release -j$(nproc)   # Linux
cmake --build build --config Release -j$(sysctl -n hw.ncpu)  # macOS

# 使用特定数量的核心
cmake --build build --config Release -j 8

# 或在 CMake 配置时设置
cmake -B build -DCMAKE_BUILD_PARALLEL_LEVEL=8
```

### 清理和重建

```bash
# 清理构建
cmake --build build --target clean

# 完全删除构建目录
rm -rf build

# 重新构建
cmake -B build && cmake --build build --config Release
```

## 后端特定构建

### CPU 构建

```bash
# 基础 CPU 构建
cmake -B build
cmake --build build --config Release

# 使用 OpenBLAS 加速
cmake -B build \
    -DGGML_BLAS=ON \
    -DGGML_BLAS_VENDOR=OpenBLAS
cmake --build build --config Release

# 使用 Intel MKL 加速
cmake -B build \
    -DGGML_BLAS=ON \
    -DGGML_BLAS_VENDOR=Intel10_64lp \
    -DCMAKE_C_COMPILER=icx \
    -DCMAKE_CXX_COMPILER=icpx
cmake --build build --config Release

# 启用 ARM KleidiAI 加速
cmake -B build \
    -DGGML_CPU_KLEIDIAI=ON
cmake --build build --config Release
```

### Metal 构建（Apple Silicon）

```bash
# Metal 是 macOS 默认后端
cmake -B build
cmake --build build --config Release

# 显式启用 Metal
cmake -B build -DGGML_METAL=ON
cmake --build build --config Release

# 禁用 Metal（仅使用 CPU）
cmake -B build -DGGML_METAL=OFF
cmake --build build --config Release
```

### CUDA 构建（NVIDIA GPU）

```bash
# 基础 CUDA 构建
cmake -B build -DGGML_CUDA=ON
cmake --build build --config Release

# 指定 CUDA 架构
cmake -B build \
    -DGGML_CUDA=ON \
    -DCMAKE_CUDA_ARCHITECTURES="86;89"
cmake --build build --config Release

# 使用非原生构建（兼容所有 GPU）
cmake -B build \
    -DGGML_CUDA=ON \
    -DGGML_NATIVE=OFF
cmake --build build --config Release

# 指定 CUDA 编译器路径
cmake -B build \
    -DGGML_CUDA=ON \
    -DCMAKE_CUDA_COMPILER=/opt/cuda/bin/nvcc
cmake --build build --config Release

# 启用统一内存（Linux）
cmake -B build \
    -DGGML_CUDA=ON \
    -DGGML_CUDA_ENABLE_UNIFIED_MEMORY=ON
cmake --build build --config Release
```

### HIP 构建（AMD GPU）

```bash
# Linux 上的 HIP 构建
HIPCXX="$(hipconfig -l)/clang" HIP_PATH="$(hipconfig -R)" \
cmake -S . -B build \
    -DGGML_HIP=ON \
    -DGPU_TARGETS=gfx1030 \
    -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

# Windows 上的 HIP 构建
cmake -S . -B build \
    -G Ninja \
    -DGPU_TARGETS=gfx1100 \
    -DGGML_HIP=ON \
    -DCMAKE_C_COMPILER=clang \
    -DCMAKE_CXX_COMPILER=clang++ \
    -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

### Vulkan 构建

```bash
# Linux 上的 Vulkan 构建
sudo apt install libvulkan-dev glslc spirv-headers
cmake -B build -DGGML_VULKAN=ON
cmake --build build --config Release

# Windows 上的 Vulkan 构建
# 确保安装了 Vulkan SDK
cmake -B build -DGGML_VULKAN=ON
cmake --build build --config Release
```

### SYCL 构建（Intel GPU）

```bash
# 安装 oneAPI
source /opt/intel/oneapi/setvars.sh

# SYCL 构建
cmake -B build \
    -DGGML_SYCL=ON \
    -DCMAKE_C_COMPILER=icx \
    -DCMAKE_CXX_COMPILER=icpx
cmake --build build --config Release
```

### MUSA 构建（Moore Threads GPU）

```bash
# 基础 MUSA 构建
cmake -B build -DGGML_MUSA=ON
cmake --build build --config Release

# 指定 MUSA 架构
cmake -B build \
    -DGGML_MUSA=ON \
    -DMUSA_ARCHITECTURES="21"
cmake --build build --config Release
```

### 多后端构建

```bash
# 同时启用 CUDA 和 Vulkan
cmake -B build \
    -DGGML_CUDA=ON \
    -DGGML_VULKAN=ON
cmake --build build --config Release

# 启用 CUDA 和 BLAS
cmake -B build \
    -DGGML_CUDA=ON \
    -DGGML_BLAS=ON \
    -DGGML_BLAS_VENDOR=OpenBLAS
cmake --build build --config Release

# macOS 上启用 Metal 和 BLAS
cmake -B build \
    -DGGML_METAL=ON \
    -DGGML_BLAS=ON
cmake --build build --config Release
```

## 高级构建选项

### 构建类型

```bash
# Release 构建（默认）
cmake -B build -DCMAKE_BUILD_TYPE=Release

# Debug 构建
cmake -B build -DCMAKE_BUILD_TYPE=Debug

# RelWithDebInfo 构建
cmake -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo

# MinSizeRel 构建
cmake -B build -DCMAKE_BUILD_TYPE=MinSizeRel
```

### 静态/动态库

```bash
# 构建共享库（默认）
cmake -B build -DBUILD_SHARED_LIBS=ON

# 构建静态库
cmake -B build -DBUILD_SHARED_LIBS=OFF

# 同时构建静态和共享库
cmake -B build -DBUILD_SHARED_LIBS=ON -DBUILD_STATIC_LIBS=ON
```

### 特定目标构建

```bash
# 只构建 llama-cli
cmake --build build --config Release -t llama-cli

# 只构建 llama-server
cmake --build build --config Release -t llama-server

# 只构建量化工具
cmake --build build --config Release -t llama-quantize

# 构建所有示例
cmake --build build --config Release -t all-examples
```

### 自定义安装路径

```bash
# 安装到自定义目录
cmake -B build -DCMAKE_INSTALL_PREFIX=/opt/llama.cpp
cmake --build build --config Release
cmake --install build

# 安装到用户目录
cmake -B build -DCMAKE_INSTALL_PREFIX=$HOME/.local
cmake --build build --config Release
cmake --install build
```

### 编译器选项

```bash
# 使用特定编译器
cmake -B build \
    -DCMAKE_C_COMPILER=clang \
    -DCMAKE_CXX_COMPILER=clang++

# 添加编译器标志
cmake -B build \
    -DCMAKE_C_FLAGS="-O3 -march=native" \
    -DCMAKE_CXX_FLAGS="-O3 -march=native"

# 链接时间优化
cmake -B build \
    -DCMAKE_INTERPROCEDURAL_OPTIMIZATION=ON
```

### 依赖管理

```bash
# 检测并使用系统依赖
cmake -B build -DLLAMA_OPENSSL=ON

# 禁用某些功能
cmake -B build \
    -DLLAMA_OPENSSL=OFF \
    -DLLAMA_CURL=OFF

# 使用预编译依赖
cmake -B build \
    -DCMAKE_FIND_PACKAGE_PREFER_CONFIG=ON
```

### 性能优化选项

```bash
# 启用本地优化
cmake -B build -DGGML_NATIVE=ON

# 禁用本地优化（可移植）
cmake -B build -DGGML_NATIVE=OFF

# 启用 OpenMP
cmake -B build -DGGML_OPENMP=ON

# 启用调试符号
cmake -B build \
    -DCMAKE_BUILD_TYPE=RelWithDebInfo \
    -DCMAKE_BUILD_RPATH_USE_ORIGIN=ON
```

## 跨平台构建

### XCFramework 构建（iOS/macOS）

```bash
# 构建 iOS/macOS 通用框架
./build-xcframework.sh

# 指定输出目录
./build-xcframework.sh --output ~/Frameworks/Llama.framework
```

### Android 构建

```bash
# 设置 Android NDK 路径
export ANDROID_NDK=/path/to/ndk

# 配置 Android 构建
cmake -B build-android \
    -DCMAKE_TOOLCHAIN_FILE=$ANDROID_NDK/build/cmake/android.toolchain.cmake \
    -DANDROID_ABI=arm64-v8a \
    -DANDROID_PLATFORM=android-28 \
    -DGGML_OPENCL=ON

cmake --build build-android --config Release
```

### WebAssembly 构建

```bash
# 安装 Emscripten
# https://emscripten.org/docs/getting_started/downloads.html

# 配置 WebAssembly 构建
cmake -B build-wasm \
    -DCMAKE_TOOLCHAIN_FILE=$EMSCRIPTEN/cmake/Modules/Platform/Emscripten.cmake \
    -DGGML_WEBGPU=ON

cmake --build build-wasm --config Release
```

### RISC-V 构建

```bash
# RISC-V 64 位构建
cmake -B build-riscv64 \
    -DCMAKE_SYSTEM_NAME=Linux \
    -DCMAKE_SYSTEM_PROCESSOR=riscv64 \
    -DCMAKE_C_COMPILER=riscv64-linux-gnu-gcc \
    -DCMAKE_CXX_COMPILER=riscv64-linux-gnu-g++

cmake --build build-riscv64 --config Release
```

## 性能优化

### 编译优化

```bash
# 最高优化级别
cmake -B build \
    -DCMAKE_BUILD_TYPE=Release \
    -DCMAKE_C_FLAGS="-O3 -DNDEBUG" \
    -DCMAKE_CXX_FLAGS="-O3 -DNDEBUG"

# 架构特定优化
cmake -B build \
    -DCMAKE_C_FLAGS="-O3 -march=haswell" \
    -DCMAKE_CXX_FLAGS="-O3 -march=haswell"
```

### 内存优化

```bash
# 禁用不必要的功能
cmake -B build \
    -DGGML_METAL=OFF \
    -DGGML_BLAS=OFF \
    -DBUILD_SHARED_LIBS=OFF

# 优化二进制大小
cmake -B build \
    -DCMAKE_BUILD_TYPE=MinSizeRel \
    -DCMAKE_INTERPROCEDURAL_OPTIMIZATION=ON
```

### 运行时优化

```bash
# 使用 ccache 加速重新编译
export PATH="/usr/lib/ccache:$PATH"
cmake -B build
cmake --build build --config Release

# 使用 Ninja 构建系统（更快）
cmake -B build -G Ninja
cmake --build build --config Release
```

## 故障排查

### 常见编译错误

#### CUDA 错误

```bash
# 检查 CUDA 安装
nvidia-smi
nvcc --version

# 检查 CUDA 路径
echo $CUDA_HOME
echo $LD_LIBRARY_PATH

# 重新配置 CUDA 构建
cmake -B build -DGGML_CUDA=ON -DCMAKE_CUDA_COMPILER=/usr/local/cuda/bin/nvcc
cmake --build build --config Release
```

#### 内存不足

```bash
# 减少并行任务
cmake --build build --config Release -j 1

# 或使用更少的优化
cmake -B build -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build --config Release
```

#### 链接错误

```bash
# 检查库路径
ldconfig -p | grep -i llama

# 重新配置并指定库路径
cmake -B build \
    -DCMAKE_LIBRARY_PATH=/usr/local/lib \
    -DCMAKE_INCLUDE_PATH=/usr/local/include
cmake --build build --config Release
```

### 构建脚本示例

```bash
#!/bin/bash
# build.sh

set -e  # 遇到错误退出

# 清理旧构建
rm -rf build

# 配置构建
cmake -B build \
    -DCMAKE_BUILD_TYPE=Release \
    -DGGML_NATIVE=ON \
    -DGGML_CUDA=ON \
    -DCMAKE_CUDA_ARCHITECTURES="86;89"

# 编译
cmake --build build --config Release -j$(nproc)

# 运行测试
./build/bin/llama-cli --version
./build/bin/llama-cli --list-devices

echo "构建完成！"
```
