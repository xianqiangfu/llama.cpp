# 最佳实践文档总览

本目录包含 llama.cpp 项目的最佳实践文档，涵盖了从模型选择到生产部署的各个方面。

## 文档列表

### 问题总结文档

#### 1. 量化精度损失问题总结
- **文件：** `量化精度损失问题总结.md`
- **内容：** 量化精度损失的常见问题、原因分析、评估方法和优化建议
- **适用：** 所有使用量化模型的用户
- **关键话题：** 困惑度增加、输出质量下降、量化方法差异

#### 2. 后端兼容性问题总结
- **文件：** `后端兼容性问题总结.md`
- **内容：** 不同硬件后端的兼容性差异、配置优化和故障排查
- **适用：** 多平台部署和后端优化
- **关键话题：** 数据类型支持、操作系统兼容性、内存管理差异

#### 3. 多设备协同问题总结
- **文件：** `多设备协同问题总结.md`
- **内容：** 多 GPU/多设备环境下的协同问题、分割模式选择和性能优化
- **适用：** 多设备环境部署
- **关键话题：** 流水线并行、张量并行、负载均衡、故障排查

## 文档使用指南

### 新用户入门

1. **第一步：** 阅读《模型选择与量化最佳实践》选择合适的模型和量化策略
2. **第二步：** 阅读《推理配置调优最佳实践》了解基本参数配置
3. **第三步：** 阅读《服务器部署与运维最佳实践》进行生产部署

### 高级用户优化

1. **性能优化：**
   - 阅读《推理配置调优最佳实践》进行详细参数调优
   - 阅读《批处理与并发最佳实践》优化吞吐量
   - 阅读《多 GPU 部署最佳实践》充分利用多 GPU

2. **问题解决：**
   - 阅读《量化精度损失问题总结》解决量化相关问题
   - 阅读《后端兼容性问题总结》解决兼容性问题
   - 阅读《多设备协同问题总结》解决多设备问题

### 开发者扩展

1. **API 使用：**
   - 阅读《二次开发与扩展最佳实践》了解 API 使用
   - 阅读《测试与验证最佳实践》学习测试方法

2. **功能开发：**
   - 参考《二次开发与扩展最佳实践》中的示例代码
   - 使用《测试与验证最佳实践》中的测试框架
