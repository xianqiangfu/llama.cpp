# 批处理与并发最佳实践

## 概述

批处理和并发是提升 llama.cpp 推理吞吐量的关键技术。本文档提供了批处理策略、并发处理方法和最佳实践的详细指南，帮助用户最大化系统吞吐量。

## 批处理基础

### 批处理类型

#### 1. 静态批处理

**特点：**
- 固定批大小
- 预知延迟
- 实现简单

**适用场景：**
- 离线处理
- 批量文本生成
- 固定工作负载

```bash
# 静态批处理
./llama-cli -m model.gguf -b 512 -f input.txt
```

#### 2. 动态批处理

**特点：**
- 动态调整批大小
- 优化吞吐延迟比
- 实现复杂

**适用场景：**
- 实时服务
- 变化工作负载
- 在线推理

```bash
# 服务器模式动态批处理
./llama-server -m model.gguf -np 8 --parallel 4
```

### 批处理参数

| 参数 | 默认值 | 说明 | 调优建议 |
|------|--------|------|----------|
| `-b, --batch-size` | 512 | 批处理大小 | 128-2048 范围 |
| `-ub, --ubatch-size` | 512 | 微批处理大小 | ≥批处理大小 |
| `-np, --n-parallel` | 1 | 并行处理数 | 根据资源调整 |
| `--n-ctx` | 512 | 上下文大小 | 影响批处理能力 |

### 批处理性能分析

**性能因素：**
1. **批大小对吞吐的影响**
```bash

    ./llama-cli -m model.gguf -b $BS -p "test" -n 1000 --time-detail
done
```

2. **内存限制**
```bash

./llama-cli -m model.gguf -b 1024 -p "test" -n 1000 --verbose
```

3. **GPU 利用率**
```bash
# 监控 GPU 利用率
watch -n 1 nvidia-smi
```

## 并发处理策略

### 并发级别

#### 1. 请求级并发

**特点：**
- 多个独立请求
- 低资源竞争
- 简单实现

**适用场景：**
- HTTP API 服务
- 多用户系统
- 低延迟要求

```bash
# 启动并发服务器
./llama-server -m model.gguf --parallel 4 -port 8080
```

#### 2. Token 级并发

**特点：**
- 同一请求内并发
- 复杂实现
- 高吞吐潜力

**适用场景：**
- 长序列生成
- 批量处理
- 高吞吐需求

```bash
# 使用较大的批处理
./llama-cli -m model.gguf -b 1024 -f large_input.txt
```

### 并发配置

#### 服务器模式并发

```bash
# 基本并发配置
./llama-server \
  -m model.gguf \
  --parallel 8 \
  --port 8080 \
  -c 4096 \
  -ngl 35

# 高并发配置
./llama-server \
  -m model.gguf \
  --parallel 16 \
  --port 8080 \
  -c 4096 \
  -ngl 35 \
  -b 1024 \
  -ub 512
```

#### 批处理并发

```bash
# 并发批处理
./llama-cli \
  -m model.gguf \
  -b 1024 \
  -t 8 \
  -f input.txt \
  -o output.txt

# 多文件并行处理
for file in inputs/*.txt; do
    ./llama-cli -m model.gguf -b 512 -f "$file" -o "outputs/$(basename $file)" &
done
wait
```

## 负载均衡策略

### 1. 轮询分配

**特点：**
- 简单公平
- 无状态
- 适合同质工作负载

```bash
# 多进程轮询
for i in {1..4}; do
    ./llama-cli -m model.gguf -b 512 -f "input_$i.txt" &
done
wait
```

### 2. 智能调度

**特点：**
- 根据负载分配
- 优化资源利用
- 实现复杂

**考虑因素：**
- 请求长度
- 资源使用
- 历史性能

### 3. 优先级队列

**特点：**
- 区分请求优先级
- 保证服务质量
- 需要队列管理

```python
# Python 优先级队列示例
import queue
import threading

request_queue = queue.PriorityQueue()

def high_priority_task():
    request_queue.put((1, "high priority request"))

def low_priority_task():
    request_queue.put((10, "low priority request"))
```

## 性能优化技巧

### 1. 内存优化

**策略：**
```bash
# 减少 KV 缓存内存
./llama-cli -m model.gguf \
  --cache-type-k q8_0 \
  --cache-type-v q8_0 \
  -b 1024

# 减少上下文大小
./llama-cli -m model.gguf \
  -c 2048 \
  -b 1024

# 启用内存映射
./llama-cli -m model.gguf \
  --mmap \
  -b 1024
```

### 2. GPU 优化

**策略：**
```bash
# 最大化 GPU 利用
./llama-cli -m model.gguf \
  -ngl all \
  -b 1024 \
  -ub 512

# 启用 Flash Attention
./llama-cli -m model.gguf \
  -fa on \
  -b 1024

# 多 GPU 分布
./llama-cli -m model.gguf \
  --split-mode layer \
  --tensor-split 2,1,1 \
  -b 1024
```

### 3. CPU 优化

**策略：**
```bash
# 优化线程数
./llama-cli -m model.gguf \
  -t 8 \
  -b 1024

# CPU 亲和性
taskset -c 0-7 ./llama-cli -m model.gguf -b 1024

# NUMA 优化
numactl --cpunodebind=0 --membind=0 ./llama-cli -m model.gguf -b 1024
```

## 监控和诊断

### 性能指标

**关键指标：**
1. **吞吐量：** tokens/s
2. **延迟：** 首token延迟，平均延迟
3. **利用率：** CPU/GPU 利用率
4. **内存使用：** VRAM，系统内存

**监控脚本：**
```bash
#!/bin/bash
# monitor_performance.sh

while true; do
    echo "=== $(date) ==="
    
    # GPU 状态
    nvidia-smi --query-gpu=utilization.gpu,memory.used,memory.total --format=csv
    
    # CPU 状态
    top -b -n 1 | head -20
    
    # 进程状态
    ps aux | grep llama-cli
    
    sleep 5
done
```

### 瓶颈分析

**常见瓶颈：**
1. **内存瓶颈**
   - 症状：OOM 错误，频繁 GC
   - 解决：减少批大小，优化 KV 缓存

2. **GPU 瓶颈**
   - 症状：GPU 利用率 100%，吞吐低
   - 解决：增加 GPU，优化模型

3. **CPU 瓶颈**
   - 症状：CPU 利用率高，GPU 利用率低
   - 解决：优化线程数，使用 BLIS

4. **I/O 瓶颈**
   - 症状：磁盘 I/O 高
   - 解决：使用 SSD，启用 mmap

## 实际应用案例

### 案例 1：批量文档生成

**需求：** 生成大量技术文档

**配置：**
```bash
#!/bin/bash
# batch_document_generation.sh

MODEL="llama-3-8b-q4_k_m.gguf"
INPUT_DIR="documents"
OUTPUT_DIR="generated"
PARALLEL=4

mkdir -p $OUTPUT_DIR

# 并发处理
find $INPUT_DIR -name "*.txt" | xargs -P $PARALLEL -I {} \
    ./llama-cli -m $MODEL -f {} -o "$OUTPUT_DIR/{##*/}" \
    -b 1024 -c 4096 -ngl 35
```

### 案例 2：实时对话服务

**需求：** 低延迟对话服务

**配置：**
```bash
#!/bin/bash
# real_time_chat_service.sh

MODEL="llama-3-8b-instruct-q4_k_m.gguf"

./llama-server \
  -m $MODEL \
  --parallel 8 \
  --port 8080 \
  -c 4096 \
  -ngl 35 \
  -b 1 \
  --temp 0.7 \
  --top-p 0.9 \
  --repeat-penalty 1.1
```

### 案例 3：代码批量生成

**需求：** 批量生成代码示例

**配置：**
```bash
#!/bin/bash
# batch_code_generation.sh

MODEL="deepseek-coder-6.7b-q4_k_m.gguf"
PROMPT_FILE="code_prompts.txt"
OUTPUT_DIR="generated_code"

mkdir -p $OUTPUT_DIR

# 按语言分类处理
while IFS= read -r line; do
    lang=$(echo $line | cut -d':' -f1)
    prompt=$(echo $line | cut -d':' -f2-)
    
    ./llama-cli -m $MODEL \
        -p "Write $lang code for: $prompt" \
        -o "$OUTPUT_DIR/${lang}_$(date +%s).py" \
        -b 512 -c 2048 -ngl 35
done < $PROMPT_FILE
```
