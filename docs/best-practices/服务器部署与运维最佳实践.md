# 服务器部署与运维最佳实践

## 概述

服务器部署和运维是 llama.cpp 生产环境的关键。本文档提供了服务器部署、运维监控、故障处理和性能优化的详细指南。

## 服务器部署

### 1. 环境准备

#### 硬件要求

| 组件 | 最低要求 | 推荐配置 |
|------|----------|----------|
| CPU | 4核心 | 16+ 核心 |
| 内存 | 16GB | 64GB+ |
| 存储 | 100GB SSD | 1TB NVMe SSD |
| GPU | 可选 | 24GB+ VRAM |
| 网络 | 1GbE | 10GbE+ |

#### 软件环境

**推荐配置：**
- **操作系统：** Ubuntu 22.04+ / CentOS 8+
- **CUDA：** 12.0+（如使用 NVIDIA GPU）
- **Python：** 3.8+
- **依赖：** 完整的构建工具链

### 2. 安装和配置

#### 构建安装

```bash
# 1. 安装依赖
sudo apt update
sudo apt install -y build-essential cmake git wget

# 2. 克隆仓库
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp

# 3. 配置构建
cmake -B build -DGGML_CUDA=ON -DCMAKE_BUILD_TYPE=Release

# 4. 编译
cmake --build build --config Release -j

# 5. 验证安装
./build/bin/llama-cli --version
```

#### 服务部署

**systemd 服务配置：**
```bash
# /etc/systemd/system/llama-server.service

[Unit]
Description=llama.cpp Server
After=network.target

[Service]
Type=simple
User=llama
WorkingDirectory=/opt/llama.cpp
ExecStart=/opt/llama.cpp/build/bin/llama-server -m /opt/models/model.gguf --port 8080
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
# 启用服务
sudo systemctl daemon-reload
sudo systemctl enable llama-server.service
sudo systemctl start llama-server.service

# 检查状态
sudo systemctl status llama-server.service
```

#### Docker 部署

```bash
# 构建 Docker 镜像
docker build -t llama-server:latest .

# 运行容器
docker run -d \
  --name llama-server \
  --gpus all \
  -p 8080:8080 \
  -v /opt/models:/models \
  llama-server:latest

# 查看日志
docker logs -f llama-server
```

### 3. 反向代理配置

#### Nginx 配置

```nginx
# /etc/nginx/sites-available/llama.cpp

upstream llama_backend {
    server localhost:8080;
}

server {
    listen 80;
    server_name api.example.com;

    location / {
        proxy_pass http://llama_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 优化设置
        proxy_http_version 1.1;
        proxy_set_header Connection "";
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Upgrade "websocket";
        proxy_connect_timeout 1h;
        proxy_send_timeout 1h;
        proxy_read_timeout 1h;
    }
}
```

#### 负载均衡

```nginx
upstream llama_cluster {
    server localhost:8080 weight=3;
    server localhost:8081 weight=3;
    server localhost:8082 weight=2;
    server localhost:8083 weight=2;
    
    least_conn;  # 最少连接负载均衡
}

server {
    listen 80;
    server_name api.example.com;
    
    location / {
        proxy_pass http://llama_cluster;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        
        # 健康检查
        health_check interval=5s fails=3 passes=2;
    }
}
```

## 运维监控

### 1. 性能监控

#### 基础监控

```bash
#!/bin/bash
# basic_monitor.sh

while true; do
    # CPU 使用率
    CPU_USAGE=$(top -b -n 1 | grep "Cpu(s)" | awk '{print $2}')
    
    # 内存使用率
    MEM_USAGE=$(free | grep Mem | awk '{print ($3/$2) * 100.0}')
    
    # GPU 使用率
    GPU_USAGE=$(nvidia-smi --query-gpu=utilization.gpu --format=csv,noheader,nounits)
    
    # 网络流量
    NET_RX=$(cat /proc/net/dev | grep eth0 | awk '{print $2}')
    NET_TX=$(cat /proc/net/dev | grep eth0 | awk '{print $10}')
    
    echo "CPU: ${CPU_USAGE}%, MEM: ${MEM_USAGE}%, GPU: ${GPU_USAGE}%, NET_RX: ${NET_RX}, NET_TX: ${NET_TX}"
    
    sleep 5
done
```

### 2. 日志管理

#### 日志配置

```bash
# 配置日志轮转
mkdir -p /var/log/llama
chown llama:llama /var/log/llama

# logrotate 配置
# /etc/logrotate.d/llama

/var/log/llama/*.log {
    daily
    rotate 14
    compress
    delaycompress
    notifempty
    create 644 llama llama
    sharedscripts
        postrotate
            systemctl reload llama-server.service > /dev/null || true
        endscript
}
```

#### 日志分析

```bash
#!/bin/bash
# analyze_logs.sh

LOG_FILE="/var/log/llama/server.log"

# 错误统计
ERROR_COUNT=$(grep -c "ERROR" $LOG_FILE)
echo "Total errors: $ERROR_COUNT"

# 性能统计
AVG_TOKENS_PER_SEC=$(grep "tokens/s" $LOG_FILE | awk '{sum+=$2; count++} END {print sum/count}')
echo "Average tokens/s: $AVG_TOKENS_PER_SEC"

# 请求统计
TOTAL_REQUESTS=$(grep -c "POST /completion" $LOG_FILE)
echo "Total requests: $TOTAL_REQUESTS"

# 响应时间统计
AVG_RESPONSE_TIME=$(grep "response_time" $LOG_FILE | awk '{sum+=$2; count++} END {print sum/count}')
echo "Average response time: $AVG_RESPONSE_TIME ms"
```

### 3. 告警系统

#### 基础告警

```bash
#!/bin/bash
# basic_alert.sh

# 检查服务状态
if ! systemctl is-active --quiet llama-server.service; then
    echo "CRITICAL: llama-server service is not running!"
    # 发送告警（邮件、Slack 等）
fi

# 检查内存使用
MEM_USAGE=$(free | grep Mem | awk '{print ($3/$2) * 100.0}')
if (( $(echo "$MEM_USAGE > 80" | bc -l) )); then
    echo "WARNING: Memory usage is ${MEM_USAGE}%"
fi

# 检查 GPU 温度
GPU_TEMP=$(nvidia-smi --query-gpu=temperature.gpu --format=csv,noheader,nounits)
if (( GPU_TEMP > 80 )); then
    echo "WARNING: GPU temperature is ${GPU_TEMP}°C"
fi
```

## 性能优化

### 1. 系统优化

#### CPU 优化

```bash
# 设置 CPU 频率
sudo cpupower frequency-set -g performance

# 设置 CPU 治理器
echo "performance" | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor

# 禁用 CPU 治理
sudo systemctl stop cpupower
```

#### 内存优化

```bash
# 设置 swappiness
echo "vm.swappiness = 10" | sudo tee -a /etc/sysctl.conf

# 设置缓存压力
echo "vm.vfs_cache_pressure = 50" | sudo tee -a /etc/sysctl.conf

# 应用设置
sudo sysctl -p
```

#### I/O 优化

```bash
# 设置 I/O 调度器
echo "deadline" | sudo tee /sys/block/sd*/queue/scheduler

# 设置读写深度
echo "64" | sudo tee /sys/block/sd*/queue/nr_requests

# 禁用访问时间
echo "0" | sudo tee /sys/block/sd*/queue/read_ahead_kb
```

### 2. GPU 优化

#### CUDA 优化

```bash
# 设置 GPU 性能模式
sudo nvidia-smi -pm 1

# 设置功耗限制
sudo nvidia-smi -pl 250

# 启用 MIG（如适用）
sudo nvidia-smi -mig 1
```

#### 显存优化

```bash
# 清理显存
nvidia-smi --gpu-reset

# 设置持久化模式
sudo nvidia-smi -pm 1
```

### 3. 网络优化

#### TCP 优化

```bash
# /etc/sysctl.conf

# TCP 缓冲区设置
net.core.rmem_max = 134217728
```

### 2. 灾难恢复

#### 备份策略

```bash
#!/bin/bash
# backup_config.sh

BACKUP_DIR="/backup/llama_config_$(date +%Y%m%d)"
mkdir -p $BACKUP_DIR

# 备份配置文件
cp -r /etc/systemd/system/llama-server.service $BACKUP_DIR/
cp -r /etc/nginx/sites-available/llama.cpp $BACKUP_DIR/
cp -r /opt/llama.cpp/config $BACKUP_DIR/

# 备份模型文件
tar -czf $BACKUP_DIR/models.tar.gz /opt/models/

# 备份日志
tar -czf $BACKUP_DIR/logs.tar.gz /var/log/llama/

echo "Backup completed: $BACKUP_DIR"
```

#### 恢复流程

```bash
#!/bin/bash
# restore_config.sh

BACKUP_DIR=${1:-"backup/llama_config_latest"}

# 停止服务
sudo systemctl stop llama-server.service

# 恢复配置
sudo cp -r $BACKUP_DIR/llama-server.service /etc/systemd/system/
sudo cp -r $BACKUP_DIR/llama.cpp /etc/nginx/sites-available/

# 重启服务
sudo systemctl daemon-reload
sudo systemctl start llama-server.service

# 验证服务
sudo systemctl status llama-server.service
```

## 安全配置

### 1. 网络安全

#### 防火墙配置

```bash
# UFW 防火墙
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS
sudo ufw enable
sudo ufw status
```

#### SSL/TLS 配置

```nginx
# /etc/nginx/sites-available/llama.cpp

server {
    listen 443 ssl http2;
    server_name api.example.com;

    ssl_certificate /etc/ssl/certs/api.example.com.crt;
    ssl_certificate_key /etc/ssl/certs/api.example.com.key;
    
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;
    
    location / {
        proxy_pass http://llama_backend;
        # ...其他配置
    }
}

# HTTP 重定向到 HTTPS
server {
    listen 80;
    server_name api.example.com;
    return 301 https://$server_name$request_uri;
}
```
