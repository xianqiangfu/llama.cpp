## 流程说明

### 1. 输入处理
- **提示词模式**: 处理完整的输入提示词（多个 tokens）
- **生成模式**: 处理单个新生成的 token
- **词嵌入**: 将 token ID 映射到嵌入向量

### 2. 位置编码
- **RoPE 旋转**: 应用旋转位置编码到 Q 和 K
- **ALiBi/长上下文**: 支持其他位置编码方案

### 3. 多头注意力层
每层包含以下步骤：

#### 3.1 输入归一化
- **预归一化**: 在注意力计算前进行 RMSNorm
- **后归一化**: 在注意力计算后进行 RMSNorm（可选）

#### 3.2 Q/K/V 计算
- **投影**: 通过线性投影计算 Q、K、V
- **分头**: 将投影结果分成多个头
- **旋转**: 对 Q 和 K 应用 RoPE 旋转

#### 3.3 KV Cache 管理
- **存储**: 首次计算时存储 K 和 V
- **检索**: 后续计算时从 cache 检索 K 和 V

#### 3.4 注意力计算
**标准 Attention**:
1. 计算注意力分数: Q * K^T
2. 缩放: 除以 sqrt(d_k)
3. 掩码: 应用因果掩码（防止未来信息泄露）
4. Softmax: 归一化为概率分布
5. 加权求和: 与 V 相乘

**Flash Attention**:
1. 分块计算注意力
2. 减少内存访问
3. 提高计算效率

#### 3.5 输出处理
- **拼接**: 合并多头输出
- **投影**: 输出线性层
- **残差**: 添加残差连接

### 4. 前馈网络 (FFN)
**SwiGLU 结构**:
1. **门控投影**: Gate = Linear(x)
2. **上采样**: Up = Linear(x)
3. **激活**: Act = SwiGLU(Gate, Up) = Swish(Gate) * Up
4. **下采样**: Down = Linear(Act)
5. **残差**: 添加残差连接

### 5. 输出层
- **最终归一化**: 应用于最后一层输出
- **语言模型头**: 投影到词汇表大小
- **Logits**: 输出词汇表概率分布（未归一化）

## 关键计算图

### GGML 计算图结构

```
输入 (Batch, Seq_Len, Embed_Dim)
    ↓
词嵌入 (查找表)
    ↓
[Layer 0-N]
    ↓
最终归一化
    ↓
线性投影 (Embed_Dim → Vocab_Size)
    ↓
输出 (Batch, Vocab_Size)
```

### 单层计算图

```
层输入
    ↓
RMSNorm → Q, K, V 投影
    ↓
RoPE 旋转 (Q, K)
    ↓
Attention(Q, K, V) + Cache
    ↓
残差连接
    ↓
RMSNorm → FFN(Gate, Up, Down)
    ↓
残差连接
    ↓
层输出
```

## 性能优化技术

### 1. Flash Attention
- 分块计算减少 HBM 访问
- 融合 Softmax 和矩阵乘法
- 减少 O(N²) 内存占用到 O(N)

### 2. KV Cache 量化
- K/V 支持 FP16、FP8、Q4 量化
- 减少显存占用
- 提高缓存命中率

### 3. 混合精度计算
- FP16/FP8 加速
- FP32 保证数值稳定性
- 动态精度切换

### 4. 计算图优化
- 算子融合
- 内存复用
- 图重用（KV cache 命中时）

## 数据流向

| 阶段 | 输入 | 输出 |
|------|------|------|
| 嵌入 | token_id | embedding_vec |
| 注意力 | hidden_state | attention_out |
| FFN | attention_out | ffn_out |
| 输出 | ffn_out | logits |

## 关键 API 函数

| 函数 | 用途 |
|------|------|
| `llama_decode()` | 执行前向传播 |
| `ggml_mul_mat()` | 矩阵乘法 |
| `ggml_norm()` | 归一化 |
| `ggml_soft_max()` | Softmax |
| `ggml_rope()` | RoPE 编码 |
| `ggml_flash_attn()` | Flash Attention |

## 配置参数

`llama_context_params` 关键字段：

| 参数 | 说明 | 影响 |
|------|------|------|
| `n_ctx` | 上下文大小 | KV cache 大小 |
| `flash_attn_type` | Flash Attention 模式 | 注意力计算效率 |
| `type_k` | K cache 数据类型 | 显存占用/精度 |
| `type_v` | V cache 数据类型 | 显存占用/精度 |
| `n_threads` | 生成线程数 | 推理速度 |
| `n_threads_batch` | 批处理线程数 | 提示词处理速度 |
