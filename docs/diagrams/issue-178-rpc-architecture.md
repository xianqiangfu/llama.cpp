# RPC 通信架构图

```mermaid
sequenceDiagram
    participant C as 客户端
    participant T as 传输层
    participant S as RPC服务器
    participant B as 后端
    participant G as GGML计算

    C->>T: 建立连接
    T->>S: 连接请求
    S-->>T: 连接确认
    T-->>C: 连接建立

    C->>T: 发送请求 (buffer_init)
    T->>S: 转发请求
    S->>B: 创建缓冲区
    B-->>S: 缓冲区句柄
    S-->>T: 返回响应
    T-->>C: 缓冲区初始化成功

    C->>T: 发送请求 (buffer_get_base)
    T->>S: 转发请求
    S->>B: 获取缓冲区基址
    B-->>S: 返回基址
    S-->>T: 返回响应
    T-->>C: 返回基址

    C->>T: 发送请求 (compute_forward)
    T->>S: 转发请求
    S->>G: 执行计算
    G->>G: 计算图执行
    G-->>S: 计算完成
    S-->>T: 返回响应
    T-->>C: 计算结果

    C->>T: 发送请求 (buffer_free)
    T->>S: 转发请求
    S->>B: 释放缓冲区
    B-->>S: 释放确认
    S-->>T: 返回响应
    T-->>C: 释放成功

    C->>T: 断开连接
    T->>S: 断开请求
    S-->>T: 断开确认
    T-->>C: 连接关闭
```

## RPC 架构说明

### 1. 通信协议
- **传输层**: 支持 TCP、Unix Socket 等
- **序列化**: 使用自定义二进制协议
- **请求/响应**: 同步 RPC 调用模式

### 2. RPC 操作
- **buffer_init**: 初始化远程缓冲区
- **buffer_get_base**: 获取缓冲区基址
- **compute_forward**: 执行前向计算
- **buffer_free**: 释放远程缓冲区

### 3. 服务器端
- **请求处理**: 接收并处理客户端请求
- **后端管理**: 管理计算后端资源
- **计算执行**: 调用 GGML 计算图

### 4. 客户端端
- **连接管理**: 建立和维护连接
- **请求发送**: 发送 RPC 请求
- **响应处理**: 处理服务器响应

### 5. 数据流
- **初始化**: 创建远程缓冲区
- **计算**: 远程执行计算任务
- **清理**: 释放远程资源

### 6. 优势
- **分布式计算**: 支持多机分布式推理
- **资源隔离**: 客户端和服务器端资源分离
- **灵活性**: 支持多种传输协议

### 7. 应用场景
- 多机 GPU 集群推理
- CPU-GPU 混合计算
- 远程推理服务
