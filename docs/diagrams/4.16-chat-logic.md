# 聊天对话业务逻辑图

## 聊天对话流程图

```mermaid
graph TB
    subgraph 聊天对话流程[聊天对话流程]
        A[接收聊天请求] --> B[初始化会话]
        B --> C[加载模型配置]

        C --> D[解析输入消息]
        D --> E{消息类型}

        E -->|用户消息| F[处理用户输入]
        E -->|系统消息| G[处理系统指令]
        E -->|助手消息| H[处理历史记录]

        F --> I[应用对话模板]
        G --> I
        H --> I

        I --> J[构建上下文]
        J --> K[管理对话历史]

        K --> L[Token编码]
        L --> M[生成回复]

        M --> N{流式输出？}

        N -->|是| O[流式生成]
        N -->|否| P[批量生成]

        O --> Q[逐Token输出]
        P --> R[完整输出]

        Q --> S[更新对话历史]
        R --> S

        S --> T{继续对话？}

        T -->|是| U[等待下一轮]
        T -->|否| V[结束对话]

        U --> D
        V --> W[返回最终结果]
    end

    style A fill:#e1f5ff
    style W fill:#e1f5ff
    style V fill:#c8e6c9
```

## 对话历史管理

```mermaid
graph TB
    subgraph 对话历史[对话历史管理]
        HISTORY[对话历史] --> ADD{添加消息}
        ADD --> UMSG[添加用户消息]
        ADD --> ASMSG[添加助手消息]
        ADD --> SYSMSG[添加系统消息]

        UMSG --> LIST[消息列表]
        ASMSG --> LIST
        SYSMSG --> LIST

        LIST --> LIMIT{历史限制}
        LIMIT -->|超出限制| TRUNC[截断历史]
        LIMIT -->|未超出| MAINTAIN[保持历史]

        TRUNC --> KEEP{保留策略}
        KEEP --> K1[保留最近N条]
        KEEP --> K2[保留重要消息]
        KEEP --> K3[智能摘要]

        K1 --> STORE[存储历史]
        K2 --> STORE
        K3 --> STORE

        MAINTAIN --> STORE

        STORE --> NEXT[准备下一轮]

        style NEXT fill:#c8e6c9
    end
```

## 对话模板处理

```mermaid
graph TB
    subgraph 对话模板[对话模板处理]
        TEMPLATE[对话模板] --> PARSE[解析模板]
        PARSE --> FILL{填充模板}

        FILL --> F1[系统指令]
        FILL --> F2[用户消息]
        FILL --> F3[助手回复]
        FILL --> F4[历史记录]

        F1 --> APPLY[应用模板规则]
        F2 --> APPLY
        F3 --> APPLY
        F4 --> APPLY

        APPLY --> FORMAT{格式化}

        FORMAT --> |格式1| FMT1[ChatML格式]
        FORMAT --> |格式2| FMT2[Llama格式]
        FORMAT --> |格式3| FMT3[自定义格式]
        FORMAT --> |格式4| FMT4[通用格式]

        FMT1 --> CONTEXT[构建上下文]
        FMT2 --> CONTEXT
        FMT3 --> CONTEXT
        FMT4 --> CONTEXT

        CONTEXT --> PREPARE[准备输入]

        style PREPARE fill:#c8e6c9
    end
```

## 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `chat_template` | 对话模板 | auto |
| `history_max` | 最大历史记录 | 10 |
| `context_max` | 最大上下文Token | 4096 |
| `system_prompt` | 系统提示 | - |
| `temperature` | 温度参数 | 0.7 |
| `max_tokens` | 最大生成Token | 512 |
| `stream` | 流式输出 | true |
| `repeat_penalty` | 重复惩罚 | 1.1 |
