## 流程说明

### 1. KV Cache 初始化
- **计算大小**: 根据模型参数和上下文大小计算所需内存
- **分配缓冲区**: 为 K 和 V 分配独立的缓冲区
- **序列映射**: 初始化序列 ID 到缓存槽位的映射

### 2. KV Cache 查询
- **命中检查**: 检查请求的位置和序列是否已缓存
- **检索 K, V**: 从缓存中读取 K 和 V 矩阵
- **使用缓存**: 直接使用缓存的 K, V 进行注意力计算

### 3. KV Cache 存储
- **计算新 K, V**: 对新 token 计算 Q、K、V
- **查找槽位**: 在缓存中寻找空闲槽位
- **KV 驱逐**: 如果缓存满，执行驱逐策略
- **写入数据**: 将新的 K、V 数据写入缓存
- **更新元数据**: 更新位置、序列等元数据信息

### 4. 序列操作

#### seq_rm (序列删除)
- 删除指定序列在位置范围内的 K, V
- 释放对应的缓存槽位
- 更新索引和映射关系

#### seq_cp (序列复制)
- 复制源序列的 K, V 到目标序列
- 创建新的序列映射
- 支持部分范围复制

#### seq_keep (保留序列)
- 删除除指定序列外的所有 K, V
- 释放其他序列的缓存槽位

#### seq_add (位置偏移)
- 为指定序列的所有位置添加偏移量
- 更新位置索引

#### seq_div (位置缩放)
- 对位置索引进行整数除法
- 用于某些压缩或跳过策略

### 5. 缓存管理

#### 碎片整理 (Defragmentation)
- 合并连续的空闲槽位
- 减少内存碎片
- 提高缓存利用率

#### SWA (Sliding Window Attention)
- 维护滑动窗口内的 K, V
- 自动淘汰超出窗口的数据
- 支持多窗口策略

#### Recurrent Cache
- 为循环模型（如 Mamba、RWKV）维护状态
- 存储中间隐藏状态
- 支持状态回滚

#### Hybrid Cache
- 混合使用不同类型的缓存
- 结合 SWA 和 Recurrent cache
- 优化不同场景的性能

### 6. 驱逐策略
- **LRU**: 最近最少使用
- **FIFO**: 先进先出
- **随机**: 随机选择槽位
- **自定义**: 基于用户定义的策略

## KV Cache 数据结构

### llama_kv_cache
```cpp
struct llama_kv_cache {
    const llama_model & model;  // 模型引用
    const llama_hparams hparams;  // 超参数

    // 缓存配置
    uint32_t n_seq_max;      // 最大序列数
    uint32_t n_pad;          // 填充大小
    uint32_t n_swa;          // SWA 窗口大小

    // 缓存数据
    std::vector<ggml_tensor *> cells_k;  // K cache 单元
    std::vector<ggml_tensor *> cells_v;  // V cache 单元

    // 序列映射
    std::vector<uint32_t> seq_to_stream;  // 序列到流映射
};
```

### KV Cache 布局
```
KV Cache = [Layer 0, Layer 1, ..., Layer N-1]
每个 Layer = [Stream 0, Stream 1, ..., Stream M-1]
每个 Stream = [K_Cells, V_Cells]
每个 Cell = [Seq_0, Seq_1, ..., Seq_K-1]
```

## 性能优化

### 1. 数据类型量化
- **FP16**: 默认类型，平衡精度和速度
- **FP8**: 减少显存占用，可能有精度损失
- **Q4_K**: 进一步量化，适合显存受限场景

### 2. 统一缓冲区
- `kv_unified`: 多序列共享缓冲区
- 减少内存分配开销
- 提高缓存局部性

### 3. 流式处理
- 支持多个并发流
- 每个流独立管理 KV cache
- 提高批处理吞吐量

### 4. 内存管理
- **mmap**: 使用内存映射减少拷贝
- **prefetch**: 预取即将使用的 K, V
- **cache line**: 对齐到缓存行提高访问效率

|------|------|
| `llama_kv_cache::clear()` | 清空缓存 |

| `llama_kv_cache::seq_div()` | 缩放位置 |

## 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `n_ctx` | 上下文大小 | 从模型读取 |
| `type_k` | K cache 类型 | `GGML_TYPE_F16` |
| `type_v` | V cache 类型 | `GGML_TYPE_F16` |
| `kv_unified` | 统一缓冲区 | true |
| `offload_kqv` | 卸载 KQV 到 GPU | true |

## 使用场景

### 1. 单序列生成
- 标准文本生成
- KV cache 随序列增长
- 自动管理内存

### 2. 多序列批处理
- 并行生成多个序列
- 每个序列独立 KV cache
- 支持不同长度

### 3. 流式对话
- 维护对话历史
- KV cache 复用
- 高效上下文切换

### 4. 状态保存/恢复
- `llama_state_save_file()`: 保存 KV cache
- `llama_state_load_file()`: 恢复 KV cache
- 支持序列级别的保存/恢复
