## 分词处理流程

```mermaid
graph TB
    subgraph 分词处理[分词处理流程]
        INPUT[输入文本] --> PREPROCESS[预处理]
        PREPROCESS --> CLEAN[文本清理]
        CLEAN --> NORMALIZE[规范化]
        NORMALIZE --> SPLIT[文本分词]

        SPLIT --> METHOD{分词方法}
        METHOD --> |WordPiece| WP[WordPiece分词]
        METHOD --> |BPE| BP[BPE分词]
        METHOD --> |Unigram| UN[Unigram分词]

        WP --> MERGE[合并子词]
        BP --> MERGE
        UN --> MERGE

        MERGE --> SPECIAL{处理特殊Token}
        SPECIAL --> |添加BOS| S1[添加开始Token]
        SPECIAL --> |添加EOS| S2[添加结束Token]
        SPECIAL --> |处理PAD| S3[处理填充Token]

        S1 --> OUTPUT[Token列表]
        S2 --> OUTPUT
        S3 --> OUTPUT
    end

    style OUTPUT fill:#c8e6c9
```

## BPE分词算法

```mermaid
graph TB
    subgraph BPE算法[BPE分词算法]
        TEXT[输入文本] --> PRE[预处理]
        PRE --> CHAR[字符级分割]
        CHAR --> FREQ{计算频率}
        FREQ --> FREQ1[统计字符对频率]
        FREQ --> FREQ2[排序字符对]

        FREQ1 --> MERGE{合并操作}
        FREQ2 --> MERGE

        MERGE --> |循环| LOOP[高频合并]
        LOOP --> FIND[找到最高频字符对]
        FIND --> COMBINE[合并为新的Token]
        COMBINE --> UPDATE[更新词表]
        UPDATE --> CHECK{完成？}

        CHECK --> |否| MERGE
        CHECK --> |是| FINAL[最终Token序列]

        style FINAL fill:#c8e6c9
    end
```

## 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `vocab_file` | 词表文件路径 | - |
| `tokenizer_type` | 分词器类型 | bpe |
| `add_bos_token` | 是否添加BOS | false |
| `add_eos_token` | 是否添加EOS | true |
| `pad_token_id` | PAD Token ID | -1 |
| `unk_token_id` | UNK Token ID | 0 |
| `max_length` | 最大序列长度 | 2048 |
