# 补全生成业务逻辑图

## 补全生成流程图

```mermaid
graph TB
    subgraph 补全生成流程[补全生成流程]
        A[接收补全请求] --> B[解析请求参数]
        B --> C[加载模型配置]

        C --> D[准备输入文本]
        D --> E[文本预处理]
        E --> F[Token编码]

        F --> G{生成模式}

        G -->|流式生成| H[流式模式]
        G -->|批量生成| I[批量模式]
        G -->|交互模式| J[交互模式]

        H --> H1[初始化生成循环]
        I --> I1[生成完整响应]
        J --> J1[用户交互循环]

        H1 --> K[生成Token循环]
        I1 --> K
        J1 --> K

        K --> L{是否停止？}

        L -->|否| M[生成下一个Token]
        M --> N[采样策略]
        N --> O[应用采样]
        O --> P[获取Token]
        P --> Q[解码Token]
        Q --> R[输出Token]
        R --> L

        L -->|是| S[生成完成]
        S --> T[返回最终结果]
    end

    style A fill:#e1f5ff
    style T fill:#e1f5ff
    style S fill:#c8e6c9
```

## 采样策略流程

```mermaid
graph TB
    subgraph 采样策略[采样策略]
        SAMPLE[采样] --> STRAT{采样类型}

        STRAT -->|Greedy| G1[选择最大概率]
        STRAT -->|Temperature| G2[温度采样]
        STRAT -->|Top-K| G3[Top-K采样]
        STRAT -->|Top-P| G4[Top-P采样]
        STRAT -->|Top-A| G5[Top-A采样]
        STRAT -->|Min-P| G6[Min-P采样]
        STRAT -->|核采样| G7[核采样]
        STRAT -->|Mirostat| G8[Mirostat采样]

        G1 --> ADJUST[参数调整]
        G2 --> ADJUST
        G3 --> ADJUST
        G4 --> ADJUST
        G5 --> ADJUST
        G6 --> ADJUST
        G7 --> ADJUST
        G8 --> ADJUST

        ADJUST --> PENALTY{应用惩罚？}

        PENALTY -->|重复惩罚| P1[惩罚重复Token]
        PENALTY -->|存在惩罚| P2[惩罚存在Token]
        PENALTY -->|频率惩罚| P3[惩罚频率]

        P1 --> FINAL[最终概率]
        P2 --> FINAL
        P3 --> FINAL

        FINAL --> CHOICE[选择Token]

        style CHOICE fill:#c8e6c9
    end
```

## 流式生成流程

```mermaid
graph TB
    subgraph 流式生成[流式生成]
        STREAM[开始流式生成] --> INIT[初始化流]
        INIT --> LOOP{生成循环}

        LOOP -->|继续| GEN[生成Token]
        GEN --> DECODE[解码Token]
        DECODE --> SEND[发送Token]
        SEND --> BUFFER{缓冲区}

        BUFFER -->|达到阈值| FLUSH[刷新缓冲区]
        BUFFER -->|未达到| LOOP

        FLUSH --> OUTPUT[输出数据]
        OUTPUT --> LOOP

        LOOP -->|完成| FINISH[结束流式生成]

        style FINISH fill:#c8e6c9
    end
```

## 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `model_path` | 模型路径 | - |
| `max_tokens` | 最大生成Token数 | 512 |
| `temperature` | 温度参数 | 0.7 |
| `top_k` | Top-K采样值 | 40 |
| `top_p` | Top-P采样值 | 0.95 |
| `repeat_penalty` | 重复惩罚 | 1.1 |
| `presence_penalty` | 存在惩罚 | 0.0 |
| `frequency_penalty` | 频率惩罚 | 0.0 |
| `seed` | 随机种子 | -1 |
| `stream` | 是否流式输出 | false |
