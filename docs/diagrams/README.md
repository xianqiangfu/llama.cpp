## 使用指南

### 查看流程图
1. 支持Markdown编辑器的工具可以直接渲染Mermaid图表
2. 可以使用在线Mermaid编辑器查看和编辑
3. 部分Git仓库平台（如GitHub、GitLab）支持自动渲染Mermaid图表

### 编辑流程图
1. 使用任何文本编辑器编辑.md文件
2. 保持Mermaid语法正确
3. 遵循现有的文件命名和组织结构
4. 添加必要的中文说明和注释

## 技术规范

### Mermaid语法规范
- 使用中文注释和标签
- 保持图表简洁清晰
- 使用颜色区分不同模块
- 添加必要的图例说明

### 文件命名规范
- 格式: `X.X-名称.md`
- X.X: 对应的Issue编号或章节编号
- 名称: 英文描述，使用连字符分隔

### 内容结构规范
- 包含主流程图
- 添加关键子流程图
- 提供参数配置表
- 添加扩展性说明

## 维护指南

### 更新流程图
1. 当代码逻辑变化时更新对应流程图
2. 保持流程图与代码实现一致
3. 添加变更日志
4. 通知相关开发者

### 添加新流程图
1. 按照现有模板创建新文件
2. 确保符合命名规范
3. 在README中添加对应条目
