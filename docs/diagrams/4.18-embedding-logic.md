# 嵌入计算业务逻辑图

## 嵌入计算流程图

```mermaid
graph TB
    subgraph 嵌入计算流程[嵌入计算流程]
        A[接收输入文本] --> B{输入类型}

        B -->|单个文本| C[单文本处理]
        B -->|文本列表| D[批量处理]
        B -->|文件输入| E[文件读取处理]

        C --> F[文本预处理]
        D --> F
        E --> F

        F --> F1[文本清理]
        F1 --> F2[分词处理]
        F2 --> F3[Token转换]

        F3 --> G{模型类型}

        G -->|BERT类型| H[双向编码器]
        G -->|GPT类型| I[单向编码器]
        G -->|专用模型| J[专用嵌入模型]

        H --> H1[池化层]
        I --> I1[池化层]
        J --> J1[池化层]

        H1 --> K[嵌入向量]
        I1 --> K
        J1 --> K

        K --> L{归一化处理}

        L -->|需要| M[L2归一化]
        L -->|不需要| N[保持原向量]

        M --> O[输出嵌入]
        N --> O

        O --> P[保存或返回结果]
    end

    style A fill:#e1f5ff
    style P fill:#e1f5ff
    style K fill:#c8e6c9
    style O fill:#c8e6c9
```

## 文本预处理流程

```mermaid
graph TB
    subgraph 文本预处理[文本预处理]
        PRE1[原始文本] --> PRE2[文本清理]
        PRE2 --> PRE3[小写转换]
        PRE3 --> PRE4[去除特殊字符]
        PRE4 --> PRE5[分词处理]
        PRE5 --> PRE6[添加特殊Token]
        PRE6 --> PRE7[Token ID转换]
        PRE7 --> PRE8[填充/截断]
        PRE8 --> PRE9[生成注意力掩码]
        PRE9 --> PROC[处理完成]
    end

    style PROC fill:#c8e6c9
```

## 嵌入池化策略

```mermaid
graph TB
    subgraph 池化策略[嵌入池化策略]
        POOL1[编码器输出] --> POOL2{池化类型}

        POOL2 -->|CLS池化| CLS[使用[CLS] Token]
        POOL2 -->|平均池化| MEAN[平均所有Token]
        POOL2 -->|最大池化| MAX[最大值池化]
        POOL2 -->|加权池化| WEIGHT[注意力加权]

        CLS --> POOL3[选择[CLS]向量]
        MEAN --> POOL4[计算平均值]
        MAX --> POOL5[计算最大值]
        WEIGHT --> POOL6[计算加权平均]

        POOL3 --> FINAL[最终嵌入向量]
        POOL4 --> FINAL
        POOL5 --> FINAL
        POOL6 --> FINAL
    end

    style FINAL fill:#c8e6c9
```

## 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `embedding_model` | 嵌入模型路径 | - |
| `batch_size` | 批处理大小 | 32 |
| `max_length` | 最大序列长度 | 512 |
| `pooling_type` | 池化类型 | mean |
| `normalize` | 是否归一化 | true |
| `output_dim` | 输出维度 | 768 |
