## GBNF语法解析流程

```mermaid
graph TB
    subgraph GBNF解析[GBNF语法解析]
        INPUT[GBNF语法文件] --> LOAD[加载语法]
        LOAD --> PARSE[解析语法]
        PARSE --> TOKENIZE[词法分析]
        TOKENIZE --> SYNTAX[语法分析]
        SYNTAX --> BUILD[构建解析树]

        BUILD --> VALIDATE{验证语法}
        VALIDATE --> |有效| RULES[生成约束规则]
        VALIDATE --> |无效| ERROR[报告错误]

        RULES --> COMPILE[编译规则]
        COMPILE --> OPTIMIZE{优化规则}
        OPTIMIZE --> O1[规则简化]
        OPTIMIZE --> O2[冲突解决]
        OPTIMIZE --> O3[性能优化]

        O1 --> FINAL[最终约束]
        O2 --> FINAL
        O3 --> FINAL

        style FINAL fill:#c8e6c9
        style ERROR fill:#ffcdd2
    end
```

## 约束采样流程

```mermaid
graph TB
    subgraph 约束采样[约束采样流程]
        GENERATE[生成开始] --> STATE[当前状态]
        STATE --> CONSTRAINT[获取约束规则]

        CONSTRAINT --> FILTER{过滤Token}
        FILTER --> |有效Token| VALID[有效Token列表]
        FILTER --> |无效Token| INVALID[无效Token列表]

        VALID --> PROB[计算概率]
        INVALID --> ZERO[设为0概率]

        PROB --> NORMALIZE[归一化概率]
        ZERO --> NORMALIZE

        NORMALIZE --> SAMPLE[采样选择]
        SAMPLE --> SELECT[选择Token]
        SELECT --> NEXT_STATE[更新状态]

        NEXT_STATE --> CHECK{继续？}
        CHECK --> |是| STATE
        CHECK --> |否| COMPLETE[生成完成]

        style COMPLETE fill:#c8e6c9
    end
```

## 回溯处理机制

```mermaid
graph TB
    subgraph 回溯处理[回溯处理机制]
        ERROR[生成错误] --> DETECT{检测错误}
        DETECT --> |语法错误| SYNTAX_ERR[语法错误]
        DETECT --> |状态错误| STATE_ERR[状态错误]
        DETECT --> |约束错误| CONSTRAINT_ERR[约束错误]

        SYNTAX_ERR --> STRATEGY{回溯策略}
        STATE_ERR --> STRATEGY
        CONSTRAINT_ERR --> STRATEGY

        STRATEGY --> S1[单步回溯]
        STRATEGY --> S2[多步回溯]
        STRATEGY --> S3[重新开始]

        S1 --> RECOVER[恢复状态]
        S2 --> RECOVER
        S3 --> RECOVER

        RECOVER --> RETRY{重试生成}
        RETRY --> |成功| SUCCESS[恢复成功]
        RETRY --> |失败| FALLBACK[回退策略]

        FALLBACK --> F1[使用无约束生成]
        FALLBACK --> F2[返回部分结果]
        FALLBACK --> F3[报告错误]

        style SUCCESS fill:#c8e6c9
        style F3 fill:#ffcdd2
    end
```

## 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `grammar_file` | 语法约束文件 | - |
| `grammar_type` | 语法类型 | gbnf |
| `max_backtrack` | 最大回溯次数 | 10 |
| `fallback_mode` | 回退模式 | none |
| `enable_cache` | 启用缓存 | true |
| `strict_mode` | 严格模式 | false |
